# Changelog

Все значимые изменения проекта «Сорока» фиксируются в этом файле.
Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — SemVer.

## [0.23.0] — 2026-10-19

### Изменено
- Убраны названия панелей («Папки», «Письма», «Письмо») — полоска над списком стала ниже, кнопки сворачивания остались.
- Оформление по умолчанию — непрозрачное окно: перетаскивание быстрое. Прозрачность включается в «Настройках → Оформление».
- Заводские настройки (категории ИИ, промпты, подписи) приведены к текущим настройкам пользователя.
- В список писем добавлены день недели перед датой («Сб 12 окт»), скрепка у писем с вложениями и крупный красный флажок.

### Добавлено
- Навигация с клавиатуры: стрелки вверх/вниз в списке писем и в панели папок, Home/End, PageUp/PageDown, прокрутка к выделенной строке.
- Кнопка «Сохранить» в разделах «Подписи» и «Оформление».
- Крестик очистки в поле поиска по письмам.
- Флажок «важное» ставится и снимается кликом прямо в списке писем.
- «Сорока» запоминает положение и размер главного окна (`window.json`) и восстанавливает их при запуске.

## [0.22.0] — 2026-10-19

### Добавлено
- Черновики: кнопка «В черновики», автосохранение каждые 20 секунд, отправка в папку с флагом `\Drafts` (у Majordomo — «Drafts», у Mail.ru — «Черновики») через IMAP APPEND.
- Двойной клик по письму в папке черновиков открывает его в окне письма; после отправки черновик удаляется с сервера и из кэша.
- Индикатор «✓ сохранено ЧЧ:ММ» в окне письма.

## [0.21.0] — 2026-10-19

### Добавлено
- Настройка «Оформление»: прозрачное окно (Mica/Acrylic) можно выключить — окно становится обычным непрозрачным, перетаскивание перестаёт тормозить.
- Удаление письма из списка клавишей `Delete` и через правый клик («Открыть», «В корзину», «Не спам», «Непрочитано»).
- Дерево папок строится по разделителю сервера: у Majordomo `INBOX.Newsletters` теперь ребёнок «Входящих», а не плоская папка.

### Исправлено
- Окно настроек перемещается за заголовок (раньше двигался только размер).
- Кнопки письма больше не вылезают вправо: ряд перенесён под строку «От:» и переносится по ширине.

## [0.20.1] — 2026-10-19

### Исправлено
- Кнопка «Очистить корзину» больше не показывается во всех папках — только в корзине (класс `hidden` перебивался правилом `display: flex`).

## [0.20.0] — 2026-10-19

### Добавлено
- **Счётчики у папок как в The Bat!**: справа у каждой папки — всего писем (серым) и непрочитанные (акцентной плашкой).
- **Дерево папок**: вложенные папки показываются со сдвигом, у родительской — треугольник сворачивания (состояние запоминается).
- **Удаление письма в корзину**: кнопка «🗑 В корзину» в шапке письма (IMAP MOVE в папку корзины ящика), письмо сразу убирается из списка и кэша.
- **Очистка корзины**: при открытой папке корзины появляется кнопка «Очистить корзину» (\Deleted + EXPUNGE на сервере).
- **«Не спам»**: для писем в папке спама — вернуть письмо во «Входящие».
- Окно настроек можно перемещать за заголовок и менять размер (правый нижний угол).

### Изменено
- Счётчики папок берутся из одной команды `get_folder_stats` (всего + непрочитанные).
- На время перетаскивания главного окна отключаются переходы панелей — движение плавнее.

## [0.19.0] — 2026-10-19

### Добавлено
- **Общие настройки** (кнопка «Настройки» в шапке): дерево «Общие → Категории ИИ / Промпты / Подписи» и «Ящики». Настройки ящика по-прежнему открываются только из контекстного меню ящика.
- **Категории ИИ стали настраиваемыми**: добавить, переименовать, выбрать цвет, задать подсказку для модели и правила «отправитель содержит / тема содержит». Порядок в списке = приоритет правил; правило срабатывает до ИИ.
- Категории по умолчанию: Обучение (курс, вебинар, обучени, семинар) и Партнёр 1С (1c.ru, 1cnw.ru, «1С Информационные письма») плюс прежние Клиент, Госорган, Финансы, Уведомление, Реклама, Личное, Осторожно.
- **Системные промпты** вынесены в настройки: разбор письма, черновик ответа, улучшение текста, перевод. Плейсхолдеры `{categories}`, `{categories_hint}`, `{subject}`, `{body}`, `{style}`, `{from}`, `{text}`; кнопка сброса к стандартным.
- **Подписи**: список и редактор (пока хранятся в настройках; вставка в письмо — вместе с черновиками).
- **Перевод письма на русский**: кнопка «🌐 Перевести» в шапке письма, перевод через GigaChat, кэшируется в базе (повторно модель не вызывается).

### Изменено
- Промпты GigaChat теперь собираются из настроек; старые разборы читаются по прежним названиям категорий.
- Бейджи категорий берут цвет из настроек.

## [0.18.2] — 2026-10-19

### Исправлено
- Окно нового письма: поле текста растягивается вместе с окном (было фиксированной высоты, ниже оставалась пустота).
- Краткое описание от ИИ в списке писем стало контрастнее: в светлой теме — почти чёрный текст, в тёмной — светлее и плотнее.

## [0.18.1] — 2026-10-19

### Исправлено
- Счётчик непрочитанных больше не показывает письма, которых нет в списке: при открытии папки догружаются все непрочитанные, даже если они лежат глубже окна загрузки.
- Окно загрузки заголовков увеличено с 30 до 200 писем — папки вроде «Входящих» с 70 письмами показываются целиком.
- Причина расхождения: счётчик брался из IMAP `STATUS` (все непрочитанные папки), а список — только последние 30 писем; у Majordomo 40 старых непрочитанных лежали вне окна.

## [0.18.0] — 2026-10-18

### Добавлено
- Цифра непрочитанных на каждой папке; на карточке ящика — суммарно по всем его папкам.
- Мгновенное переключение папок: список сразу показывается из локального кэша, обновление с сервера идёт следом и не блокирует интерфейс.
- Кэш писем по папкам: у каждой папки своя локальная копия, папки больше не затирают друг друга.

### Изменено
- После проверки почты счётчики обновляются по IMAP STATUS для всех папок ящика (без открытия папок).
- Отметки «прочитано/непрочитано» и «важное» теперь сохраняются в кэш для любой папки, а не только для «Входящих».
- Старый кэш одной папки при первом запуске пересоздаётся; письма подтягиваются синхронизацией.

## [0.17.0] — 2026-10-18

### Добавлено
- Сортировка списка писем: кнопка «⇅» рядом с поиском — «Сначала новые» (по умолчанию) и «Сначала старые». Выбор запоминается.
- Группировка списка: «По датам» (Сегодня, Вчера, На этой неделе, В этом месяце, Раньше), «По категориям» (Важное, затем категории ИИ и «Без разбора») или «Без группировки». У каждой группы — счётчик писем.
- Переключатель темы стал одной кнопкой: она показывает тему, на которую переключит (☀ из тёмной, 🌙 из светлой), подсказка меняется вместе с ней.

### Изменено
- Важные письма больше не поднимаются наверх принудительно: список идёт строго по выбранной сортировке, важность отмечена звёздочкой.
- Группировка и сортировка работают вместе с поиском: сначала фильтр, потом порядок и заголовки групп.

## [0.16.0] — 2026-10-18

### Добавлено
- Светлая и тёмная темы: переключатель «☀ / 🌙» в шапке окна, выбор запоминается и применяется при следующем запуске.
- Если тема ещё не выбрана, «Сорока» следует системной теме Windows и переключается вместе с ней.
- Окно перекрашивается целиком: Mica/Acrylic, меню, окна настройки, календаря и письма, тосты и строки состояния — всё в тон выбранной теме.
- Светлая палитра с усиленным контрастом: категории писем, звёздочка важности, счётчики непрочитанных и кнопки читаются на белом.

### Изменено
- Цвета интерфейса переведены на единые переменные (`--bg-app`, `--bg-card`, `--bg-elev`, `--surface1/2`, `--accent-*`, `--ok/--danger`, тени) — новые экраны автоматически поддерживают обе темы.

## [0.15.0] — 2026-10-18

### Добавлено
- Несколько ящиков: панель папок показывает каждый ящик отдельной карточкой — активный раскрыт и подсвечен, остальные свёрнуты со счётчиком непрочитанных (как в The Bat!).
- «＋ Добавить ящик» внизу панели и пункт «Добавить ящик…» в меню ящика: новый ящик добавляется тем же мастером настройки.
- Меню ящика по правому клику: «Открыть ящик», «Проверить почту», «Настройки ящика…», «Добавить ящик…».
- Настройки каждого ящика открываются отдельно — со своими адресом, серверами, портами и подсказкой про пароль приложения.
- У каждого ящика свои папки, свой кэш писем и свой ИИ-разбор; отправка идёт через SMTP активного ящика.

### Изменено
- Настройки ящиков переехали в `%APPDATA%\Soroka\accounts.json` (список). Прежний `account.json` читается один раз и превращается в первый ящик — заново настраивать не нужно.
- Папки в кэше адресуются ключом «ящик::папка»; старый кэш без ключей заменяется при первой синхронизации.
- Если ящик пропал из настроек, панель сама перечитывает список и не показывает «мёртвых» ящиков.

## [0.14.1] — 2026-10-18

### Исправлено
- Настройка почты: вместо системного выпадающего списка — собственный тёмный список провайдеров (прежний рисовался светлым пятном в тёмной теме).
- Окно настройки сразу показывает текущие параметры ящика (адрес, серверы, порты) — видно, что и где менять; пароль можно не вводить, если менять не нужно (сохранится прежний).
- Поле пароля подписано «Пароль или «пароль приложения»» с подсказкой для Gmail и Яндекса.

## [0.14.0] — 2026-10-18

### Добавлено
- Мастер настройки почты: кнопка «⚙ Настройки» в шапке и автоматический показ при первом запуске (когда ящик ещё не настроен).
- Быстрые пресеты провайдеров: Mail.ru, Яндекс, Gmail, Outlook/Hotmail, Rambler и «Другое (вручную)» — IMAP/SMTP-серверы и порты подставляются сами.
- Проверка входа перед сохранением: «Сорока» подключается по IMAP и показывает число папок либо понятную ошибку (неверный пароль, недоступный сервер).
- Окно нового письма можно перетаскивать за заголовок и растягивать за правый нижний угол.
- Кнопка «✨ Улучшить» в окне письма: GigaChat исправляет орфографию и пунктуацию, делает тон деловым — смысл и факты сохраняются.

## [0.13.0] — 2026-10-18

### Добавлено
- Даты и сроки из писем: ИИ-разбор извлекает события («17–18 октября», «до 15 ноября», «15.10.2026», «завтра в 10:30», «с 14 по 20 октября» и т.п.).
- Кнопка-календарик «📅 …» в карточке письма открывает форму события с заполненными полями (название, дата, «по», время, описание) — событие попадает в календарь только после подтверждения человеком.
- Календарь в приложении: месячная сетка, список дня, навигация по месяцам, «Сегодня»; события хранятся в SQLite, удаление — из карточки дня.
- Экспорт события в файл `.ics` (в «Загрузки») — для календаря Windows.
- Черновик ответа «в моём стиле» (кнопка «✍ Черновик»): GigaChat читает письмо и образцы из «Отправленных», предлагает текст; открывается форма ответа (кому, тема «Re: …») — человек правит и отправляет сам.

### Исправлено
- В календарь больше не попадают письма из спама/корзины и реклама; автоматического добавления событий нет вовсе.
- В источнике события видна тема письма (а не только «письмо из «INBOX»»); тема сохраняется вместе с разбором.

## [0.12.0] — 2026-10-16

### Добавлено
- Свободная компоновка панелей: перетаскивание за заголовок в любые ряды — 3 в ряд, 2+1, 1+2, три ряда; индикатор места вставки.
- Плавное сворачивание: панель в ряду — в полоску «⟨/›», единственная в ряду — в плашку; соседи занимают освободившееся место (анимация).
- Разделители в двух направлениях (панели и ряды), двойной клик — сброс; раскладка запоминается между запусками.
- Пресеты раскладки — кнопка «Раскладка» в шапке окна: «Классика», «Чтение» (письмо на всю ширину), «Моя» (+ «Сохранить как «Моя»»), «Сбросить компоновку».
- Дефолтная раскладка — по настройке пользователя: [Папки|Письма|Письмо], узкие папки, широкое письмо.

### Изменено
- Шапка письма стала компактной: две строки (тема + дата / отправитель + кнопки), строка UID убрана — ≈25 % → ≈10 % высоты панели.

## [0.11.0] — 2026-10-15

- Панели: тянущиеся разделители (двойной клик — сброс), сворачивание в полоски «⟨»/«›», раскладка запоминается между запусками.

## [0.10.1] — 2026-10-15

### Исправлено
- Разрыв IMAP-соединения сервером (`* BYE`) больше не роняет операцию: «Сорока» автоматически повторяет попытку один раз через 0,7 с (папки, письма, флаги, переносы, вложения).
- Понятное сообщение при обрыве: «сервер прервал соединение — попробуйте ещё раз» вместо технического текста.
## [0.10.0] — 2026-10-15

### Добавлено
- ИИ-разбор почты (GigaChat): структурированный JSON на письмо — сводка, категория, важность, даты, задачи, действия.
- Фоновый «ИИ-индекс»: после синхронизации разбираются до 30 писем INBOX (прогресс в статус-баре), результаты кэшируются в SQLite навсегда.
- Список: строка «✦ сводка», бейджи категорий (реклама / клиент / госорган / финансы / уведомление / личное / мошенничество), важные — вверх, «⚑» у отмеченных.
- Карточка «✦ Разбор» в письме: кнопки «⚑ В важные / Снять» (IMAP `\Flagged`) и «В спам» (IMAP MOVE + локальный чёрный список домена).
- Тост «Сорока нашла N важных писем» после разбора.
## [0.9.0] — 2026-10-15

### Добавлено
- Кнопка «✦ Кратко»: краткое резюме письма от GigaChat (OAuth + chat/completions; корневой сертификат Минцифры вкомпилирован).
- Ключ GigaChat — вне репозитория: `SOROKA_GIGACHAT_KEY` или `%APPDATA%\Soroka\gigachat.json`.
- Кэш токена, обрезка письма до 4000 символов, чистка markdown в ответе; понятные ошибки (нет ключа / сеть / API).
## [0.8.0] — 2026-10-15

- Открытие письма автоматически помечает его прочитанным (в т. ч. на сервере); кнопка «Непрочитано» возвращает флаг.

## [0.6.0] — 2026-10-15

### Добавлено
- Ответ и пересылка: кнопки в просмотре письма, форма с заполненными полями (Кому, «Re:/Fwd:», цитата исходного).
- Вложения входящих: чипы под письмом, сохранение в «Загрузки» (безопасные имена, уникализация).
- Вложения при отправке: «Прикрепить файлы» (системный диалог), лимиты ≤ 15 МБ/файл и ≤ 20 МБ суммарно, отправка multipart/mixed.
- «Показать картинки»: внешние изображения заблокированы по умолчанию (CSP на рендере), кнопка включает их для одного просмотра.
- Метаданные вложений кэшируются вместе с телом (`bodies.attachments`, JSON; миграция схемы для существующих БД).
## [0.5.0] — 2026-10-15

### Добавлено
- Тело письма: клик по письму показывает содержимое — HTML (безопасно, в sandbox-iframe) или обычный текст.
- Разбор MIME на Rust (`mail-parser`): кодировки (UTF-8, windows-1251 и др.), base64, quoted-printable.
- Санитизация HTML (`ammonia`): скрипты и опасные атрибуты вычищаются; внешние картинки заблокированы (показывается alt-текст).

- Ленивая загрузка: тело запрашивается только при клике; части > 512 КБ усекаются с пометкой.
