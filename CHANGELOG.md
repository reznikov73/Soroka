# Changelog

Все значимые изменения проекта «Сорока» фиксируются в этом файле.
Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — SemVer.

## [0.10.0] — 2026-10-15

### Добавлено
- ИИ-разбор почты (GigaChat): структурированный JSON на письмо — сводка, категория, важность, даты, задачи, действия.
- Фоновый «ИИ-индекс»: после синхронизации разбираются до 30 писем INBOX (прогресс в статус-баре), результаты кэшируются в SQLite навсегда.
- Список: строка «✦ сводка», бейджи категорий (реклама / клиент / госорган / финансы / уведомление / личное / мошенничество), важные — вверх, «⚑» у отмеченных.
- Карточка «✦ Разбор» в письме: кнопки «⚑ В важные / Снять» (IMAP `\Flagged`) и «В спам» (IMAP MOVE + локальный чёрный список домена).
- Тост «Сорока нашла N важных писем» после разбора.
## [0.9.0] — 2026-10-15

### Добавлено
- Кнопка «✦ Кратко»: краткое резюме письма от GigaChat (OAuth + chat/completions; корневой сертификат Минцифры вкомпилирован).
- Ключ GigaChat — вне репозитория: `SOROKA_GIGACHAT_KEY` или `%APPDATA%\Soroka\gigachat.json`.
- Кэш токена, обрезка письма до 4000 символов, чистка markdown в ответе; понятные ошибки (нет ключа / сеть / API).
## [0.8.0] — 2026-10-15

### Добавлено
- Непрочитанные письма: акцентная точка и жирная тема в списке (флаги `\Seen` с сервера, кэш в SQLite).
- Открытие письма автоматически помечает его прочитанным (в т. ч. на сервере); кнопка «Непрочитано» возвращает флаг.
- Поиск над списком: мгновенная фильтрация по теме и отправителю (регистр не важен); «Сорока ничего не нашла», если пусто.
- Миграция кэша: колонка `seen` у `messages` для существующих баз.
## [0.7.0] — 2026-10-15

### Добавлено
- Тёмная тема в стиле Fluent 2: палитра Windows 11, системный акцент `#60cdff`, скругления, карточки панелей.
- Акриловое окно: Mica на Windows 11 с фолбэком на Acrylic (Windows 10; проверено наглядно).
- Своя шапка окна: перетаскивание, кнопки свернуть/развернуть/закрыть, двойной клик — развернуть.
- Список писем: карточки с аватарами-буквами отправителя и кратким временем; выделение акцентной полосой.
- Кнопка «Написать» — наверху левой панели; тёмные формы, тосты, скроллбары.
## [0.6.0] — 2026-10-15

### Добавлено
- Ответ и пересылка: кнопки в просмотре письма, форма с заполненными полями (Кому, «Re:/Fwd:», цитата исходного).
- Вложения входящих: чипы под письмом, сохранение в «Загрузки» (безопасные имена, уникализация).
- Вложения при отправке: «Прикрепить файлы» (системный диалог), лимиты ≤ 15 МБ/файл и ≤ 20 МБ суммарно, отправка multipart/mixed.
- «Показать картинки»: внешние изображения заблокированы по умолчанию (CSP на рендере), кнопка включает их для одного просмотра.
- Метаданные вложений кэшируются вместе с телом (`bodies.attachments`, JSON; миграция схемы для существующих БД).
## [0.5.0] — 2026-10-15

### Добавлено
- Тело письма: клик по письму показывает содержимое — HTML (безопасно, в sandbox-iframe) или обычный текст.
- Разбор MIME на Rust (`mail-parser`): кодировки (UTF-8, windows-1251 и др.), base64, quoted-printable.
- Санитизация HTML (`ammonia`): скрипты и опасные атрибуты вычищаются; внешние картинки заблокированы (показывается alt-текст).
- Кэш тел в SQLite (`bodies`): повторное открытие — мгновенно; в офлайне письма с кэшем читаются, без кэша — понятное сообщение.
- Ленивая загрузка: тело запрашивается только при клике; части > 512 КБ усекаются с пометкой.
## [0.4.1] — 2026-10-15

### Исправлено
- Список папок стал кликабельным: письма любой папки открываются в «Сороке» (раньше грузился только INBOX) — например, «INBOX/ToMyself», куда mail.ru складывает письма «от себя».
- Добавлены команда `sync_folder` и кодирование имён папок в modified UTF-7 (кириллица: «Отправленные», «1с Рассылки» и т. п.).
## [0.4.0] — 2026-10-15

### Добавлено
- Отправка писем через SMTP (`lettre`, native-tls): форма «Написать» (Ctrl+N) — Кому/Тема/Текст.
- Отправка кнопкой или Ctrl+Enter; Esc — закрыть; индикация «Отправляем…»; тост «Письмо улетело».
- Валидация адреса получателя; понятные ошибки отправки (тост, форма остаётся открытой, приложение живо).
- Настройки SMTP: `smtp_host`/`smtp_port` из account.json (иначе вывод из IMAP-хоста; порт 465), env `SOROKA_SMTP_HOST`/`SOROKA_SMTP_PORT`.
- Живой тест отправки (`cargo test --lib -- --ignored`, тест `live_send`): письмо доставлено.
## [0.3.0] — 2026-10-15

### Добавлено
- Локальный кэш SQLite (`rusqlite` bundled): письма, папки, метаданные — `%APPDATA%\Soroka\soroka.db` (вне репозитория).
- Мгновенный старт: список показывается из кэша ещё до выхода в сеть; автосинхронизация обновляет кэш.
- Офлайн-режим: без сети показываются сохранённые письма; статус «почта: офлайн, писем N»; тост-предупреждение.
- Полная замена INBOX-кэша при каждой синхронизации (без дублей); unit-тесты store (in-memory).
## [0.2.0] — 2026-10-14

### Добавлено
- Подключение к ящику по IMAP (Mail.ru: `imap.mail.ru:993`, TLS); крейт `imap` 3.0.0-alpha (точный пин).
- Синхронизация INBOX: последние 30 писем (отправитель, тема, дата, UID); дерево папок с сервера.
- Интерфейс: список писем, детали выбранного письма, кнопка «Проверить почту», автосинхронизация при запуске.
- Тост «Сорока на хвосте принесла — N писем»; статус-бар показывает число писем.
- Декодирование RFC 2047 (B/Q; UTF-8/Windows-1251/KOI8-R) для тем и имён, mUTF-7 для папок; unit-тесты (6 шт).

### Хранение учётки
- `%APPDATA%\Soroka\account.json` (вне репозитория) или переменные `SOROKA_IMAP_USER` / `SOROKA_IMAP_PASS`.
## [0.1.0] — 2026-10-14

### Добавлено
- Каркас приложения: Rust + Tauri 2, интерфейс Vite + TypeScript (vanilla), identifier `com.soroka.app`.
- Модули-заглушки: `mail/` (imap, smtp, parser, store) и `ai/` (summarize, draft_reply, classify).
- Команды `ping` и `app_info`; трёхпанельный каркас интерфейса; статус-бар «Soroka vX.Y.Z+g<hash> · backend OK».
- Версионирование из единого источника: `tauri.conf.json` → `sync-version.ps1` → Cargo/package/установщик/рантайм.
- Вшивание git-хеша в сборку (`build.rs` → `SOROKA_GIT_HASH`); отображается в статус-баре.
- NSIS-установщик (per-user, языки EN/RU, без прав администратора); окно 1280×800.
- Задачи и отладка VS Code; скрипты окружения (`devshell.ps1`, `vsc-task.ps1`, `code.ps1`); `debug-prep` для F5.

### Известные ограничения
- Память в простое ≈317 МБ суммарно (WebView2) — выше цели 150 МБ; возможная оптимизация — отдельная задача.
- Установщик не подписан: при первом запуске Windows может показать SmartScreen — «Подробнее → Выполнить в любом случае».
