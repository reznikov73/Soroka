# TASK-059 — слой 3а: строка списка по макету

Дата: 2026-11-03. Версия: 0.46.12. План: [DESIGN-PLAN.md](DESIGN-PLAN.md).

## 1. Что сделано

- **Заголовок группы:** добавлена цветная точка категории (цвет берётся из настроек категорий через `categoryBadge`). Для групп по датам точка нейтральная. Количество писем осталось справа.
- **Строка письма:** отправитель переехал на первую строку и стал жирным, тема — второй строкой, сводка ИИ — третьей. Это сделано порядком flex-элементов (`order`), без перестройки DOM.
- **Флажок «важное»** вынесен к левому краю строки и больше не исчезает при наведении (раньше он прятался вместе со временем).
- **Плотный режим** сохранён: одна строка, отправитель не жирный, порядок прежний.

Сниппет (превью текста письма) в этот слой не входит: в заголовках писем текста нет, это отдельная задача с запросом к кэшу тел.

## 4. Риски и что проверить

- **Порядок строк** изменён через CSS `order`, а не перестройкой DOM: тема и время остались в `.l1`, отправитель в `.meta`. Если где-то рассчитывается высота строки (плотный режим, уведомления), стоит проверить визуально.
- **Флажок слева** абсолютно спозиционирован внутри строки; при наведении должен оставаться видимым, а панель действий — появляться справа.
- **Три состояния** (текущая, группа выделенных, непрочитанное) не трогались, но проверить нужно: подсветка могла поехать из-за нового `padding-left: 28px`.
- **Тёмная тема:** точка группы и жирный отправитель должны читаться.
