# TASK-036 — ответ всем, поиск по тексту, перетаскивание и горячие клавиши

Версия: **0.33.0**. Дата: 2026-10-20.

## 1. «Ответить всем» (P1)
Рядом с «Ответить» появилась кнопка «Ответить всем». Адреса берутся у сервера: `imap::fetch_recipients` читает заголовки `To` и `Cc` (с переносами строк), `addresses_only` оставляет только сами адреса, отбрасывая имена и комментарии. Собственный адрес ящика и дубликаты отфильтровываются, остальные попадают в «Кому».
Файлы: `imap.rs`, `commands/mod.rs` (`message_recipients`), `index.html`, `main.ts`.

## 2. Поиск по тексту письма (P1)
В режиме «в папке» поиск теперь двухступенчатый: мгновенно фильтруется кэш по теме и отправителю, затем через 250 мс запрашивается `search_messages` с `folder` — он ищет и в тексте уже загруженных писем. Найденное только в тексте показывается отдельным блоком «В тексте письма · N». Поиск по-прежнему регистронезависимый для кириллицы (сравнение в Rust, не в SQL).
Файлы: `store.rs` (`search_messages` c `LEFT JOIN bodies` и полем `in_body`), `commands/mod.rs`, `main.ts`.

## 3. Перетаскивание писем в папки (P1)
Строку письма (или всё выделение) можно перетащить на папку в дереве: папка подсвечивается пунктиром, при отпускании вызывается `move_messages` → IMAP `MOVE` одним соединением, кэш и счётчики обновляются. Между разными ящиками перенос запрещён (сервер не поддерживает).
Файлы: `imap.rs` (`move_many_to_folder`), `commands/mod.rs` (`move_messages`), `main.ts`.

## 4. Инлайн-ответ из списка (P2)
В строке письма при наведении появилась кнопка «↩». Она раскрывает мини-форму ответа прямо под строкой: текст, «Отправить», «Отмена», статус. Отправка идёт тем же `send_mail`, что и обычное письмо; тема получает `Re:`.
Файл: `main.ts` (`inlineReplyBox`), `styles.css`.

## 5. Отмена для «В спам» (P2)
Как и удаление, перенос в спам теперь отложенный: письмо гаснет, 7 секунд в тосте есть «Отменить», затем уходит `move_to_spam`. Отмена возвращает строку без обращений к серверу.
Файл: `main.ts` (`requestSpam`/`undoSpam`/`commitSpam`).

## 6. J/K/R/E (P2)
`J`/`K` — следующее/предыдущее письмо (с прокруткой), `R` — ответ, `E` — в корзину с отменой. Не срабатывают, когда фокус в поле ввода или открыт модальный слой.
Файл: `main.ts` (`initMailHotkeys`).

## 7. Плотный список (P3)
Настройки → Оформление → «Плотный список: одна строка на письмо». CSS-режим `body.dense-list`: тема и отправитель в одной строке, без строки ИИ-резюме. Хранится в `settings.json` (`appearance.dense_list`).
Файлы: `settings.rs`, `index.html`, `styles.css`, `main.ts`.
