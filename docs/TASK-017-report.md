# TASK-017 — отчёт: светлая и тёмная тема

## Что сделано
- В шапке окна появился переключатель из двух кнопок: «☀» (светлая) и «🌙» (тёмная). Активная тема подсвечена акцентным цветом, у каждой кнопки есть подсказка.
- Выбор хранится в `localStorage["soroka.theme"]` и применяется при следующем запуске. Пока выбора нет — берётся системная тема Windows (`prefers-color-scheme`), и «Сорока» следует за её сменой.
- Переключение мгновенное, без перезапуска: меняется `data-theme` на `<html>`, все цвета читаются из CSS-переменных.
- Окно перекрашивается целиком: новая Rust-команда `set_window_theme(dark)` заново применяет Mica (Windows 11) или Acrylic (Windows 10) в тон теме и переключает системный заголовок (`window.set_theme`).
- Цвета интерфейса сведены в единые переменные: `--bg-app`, `--bg-card`, `--bg-elev`, `--bg-scrim`, `--surface1/2`, `--edge`, `--accent-*`, `--ok/--danger`, `--shadow-menu/-card`, `--text-strong`. В светлой теме — отдельный блок `html[data-theme="light"]`.
- Светлая палитра: акцент `#0f6cbd` (вместо голубого `#60cdff`), тёмный текст на светлых поверхностях, отдельные цвета для категорий писем, звёздочки важности, счётчиков непрочитанных, статусов «ок»/«ошибка».

## Решения
- Тема ставится классом-атрибутом на `<html>` (`data-theme`), а не классом на `body`: так переменные видны и внутри модальных окон, и в iframe-обёртках.
- Светлая тема — не инверсия тёмной: подобранная палитра (акцент #0f6cbd, серые поверхности с малой прозрачностью), чтобы текст оставался контрастным, а полупрозрачные панели не «просвечивали» обоями.
- Mica/Acrylic переприменяется из Rust, потому что из JS параметр `dark` для эффекта окна не изменить.
- Кнопки ☀/🌙 живут в своей группе и не наследуют 44-пиксельную ширину кнопок управления окном.
