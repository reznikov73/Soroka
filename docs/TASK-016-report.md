# TASK-016 — Отчёт (несколько почтовых ящиков)

**Статус:** выполнен; живой тест пройден. **Дата:** 2026-10-18. **Версия:** 0.15.0.

## Что изменилось для человека
1. Панель папок как в The Bat!: каждый ящик отдельной карточкой — активный раскрыт
   (папки с иконками, INBOX подписан «Входящие»), остальные свёрнуты и показывают
   счётчик непрочитанных; внизу «＋ Добавить ящик».
2. Меню ящика по правому клику: «Открыть ящик», «Проверить почту»,
   «Настройки ящика…», «Добавить ящик…» — настройки открываются для конкретного ящика
   и сразу с его адресом и серверами.
3. Мастер настройки умеет и новое, и правку: «⚙ Настройки» — активный ящик,
   «Добавить ящик» — пустая форма «Новый ящик»; пустой пароль у существующего = не менять.
4. У каждого ящика своё: папки, кэш писем, ИИ-разбор, отправка через свой SMTP.

## Как устроено
- `src-tauri/src/mail/accounts.rs` (новый): `Account`, `AccountView`,
  `load_accounts`/`save_accounts`, `upsert_account`, `folder_key`/`split_key`/`resolve_cfg`.
  Настройки — `%APPDATA%\Soroka\accounts.json`; старый `account.json` мигрирует в ящик «1».
- Ключ папки `id::ИМЯ`: все команды с папкой (тело, прочитано, важное, спам,
  вложения, синхронизация, анализ, черновик) достают настройки подключения из ключа.
- `store::save_sync(account_id, …)` переписывает папки только своего ящика, в `meta`
  пишется `account`; `CachedMail.account` / `CacheInfo.account` — чтобы не показывать
  чужой кэш под активным ящиком.
- `send_mail(account_id, …)`; `get_accounts`, `mail_account_details(account_id)`,
  `save_mail_account(account_id?, …)` → `SavedAccount { id, message }`.
- UI: `accounts`, `activeAccountId`, `renderFolders` (группы), `activateAccount`,
  `openAcctMenu`, `openSettings(firstRun, forNew, accountId?)`.
