# TASK-067 — звезда слева от строки

Дата: 2026-11-04. Версия: 0.46.19.

## Причина

Кнопка-звезда создавалась внутри блока времени (`time.append(flag)`), а сам блок времени в TASK-063 получил `position: absolute; right: 12px`. Абсолютно позиционированный элемент становится точкой отсчёта для своих абсолютных потомков — поэтому `left: 6px` у звезды отсчитывался от правого края блока времени, и звезда оказывалась рядом с датой.

## Исправление

- Звезда больше не вкладывается в блок времени: `time.append(flag)` убран.
- В строку она добавляется отдельно: `li.prepend(flag)`.
- CSS не менялся: `.flag-btn` по-прежнему `position: absolute; left: 6px; top: 50%`, но теперь ближайший позиционированный предок — сама строка `.m-row`.
