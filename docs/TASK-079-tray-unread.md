# TASK-079 — Точка непрочитанного на иконке трея

Дата: 2026-11-13. Версия: 0.46.35.

## Постановка

Из дорожной карты (обсуждение 2026-11-13): иконки трея с красной точкой были нарисованы ещё в TASK-073 (`tray.png`, `tray-alert-1.png`, `tray-alert-2.png`), но к коду не подключены — в трее всегда висела иконка приложения, и по ней нельзя было понять, есть ли непрочитанное, не разворачивая окно.

## Решения

- Основа трея — `tray.png` (конверт), при непрочитанных — `tray-alert-1.png` (тот же конверт с красной точкой). `tray-alert-2.png` оказался пиксельно идентичен первому (проверено сравнением), поэтому не используется.
- Иконки зашиты в бинарник через `include_bytes!`: рядом с установленным exe папки `icons` нет, файл с диска не прочитать.
- Для декодирования PNG добавлена фича `image-png` у зависимости `tauri` (в default-набор не входит).
- Команда `set_tray_unread(unread)` меняет иконку и подсказку трея: `POS Mail` или `POS Mail — 3 непрочитанных письма` (склонение учитывается).
- Фронтенд зовёт её из `updateWindowTitle()` — это единственное место, где считается общее число непрочитанных; вызов идёт только при смене числа, чтобы не дёргать IPC на каждый рендер папок.

## Сделано

- `src-tauri/Cargo.toml` — `tauri` features: `["tray-icon", "image-png"]`.
- `src-tauri/src/commands/mod.rs` — `tray_icon_for()`, `set_tray_unread`, `plural_pisem`.
- `src-tauri/src/lib.rs` — команда в `generate_handler!`, стартовая иконка трея из `tray.png` (фолбэк — иконка приложения).
- `src/main.ts` — `lastTrayUnread` и вызов `set_tray_unread` из `updateWindowTitle()`.

- Идея на будущее: подсказка трея может показывать число писем в папке «Входящие» активного ящика, а не сумму по всем.
