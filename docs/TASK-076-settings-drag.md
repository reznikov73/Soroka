# TASK-076 - Быстрое перетаскивание окна настроек за заголовок сайдбара

Дата: 2026-11-12. Версия: 0.46.32.

## Постановка

Окно настроек передвигается медленно. Просьба: сделать перемещение быстрым. Попутно спрашивали, как в целом улучшить скорость и потребление памяти.

## Причина

В окне настроек работали два механизма перетаскивания:

- верхняя полоса окна (`#titlebar`) — уже нативный `startDragging()` (TASK-074), быстрый путь;
- заголовок «Настройки» в сайдбаре (`.sn-head`) — код TASK-021: на каждое движение мыши сдвигал всю оболочку через CSS `transform`. В отдельном окне настроек это бессмысленно и медленно: возится большой блочный элемент внутри окна, а не само окно; перерисовка на каждый pointermove.

## Решение

- В отдельном окне настроек (`body.settings-window`) `.sn-head` теперь вызывает нативный `startDragging()` — системный захват, без IPC на каждый кадр, скорость как у обычного окна Windows.
- Встроенному оверлею настроек в главном окне системный захват не подходит (окно главное, двигать надо карточку) — там сохранён прежний transform-сдвиг.
- Права на `startDragging` у окна `settings-*` уже выданы в `capabilities/default.json`.

## Сделано

- `src/main.ts` — `makeSettingsMovable()` раздвоена по режиму: нативный захват для окна настроек, transform-сдвиг для встроенного оверлея.
- Версия `0.46.32` (`tauri.conf.json` + `sync-version.ps1`), раздел в `CHANGELOG.md`.
