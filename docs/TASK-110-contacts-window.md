# TASK-110 — Контакты в отдельном окне

Дата: 2026-11-17. Версия: 0.46.59.

## Постановка

Контактная книга была оверлеем в главном окне. Владелец попросил вынести её в отдельное окно — так же, как сделаны настройки.

## Решение

- Кнопка с человечком в шапке больше не открывает оверлей: она открывает **одно** окно контактов (повторный клик поднимает уже открытое).
- Окно создаётся по той же схеме, что настройки: своя шапка, ручки по краям и углам, кнопки «свернуть / развернуть / закрыть», двойной клик по шапке, минимум 760×520.
- В окне поднимается существующая книга: `initContacts()` вешает обработчики (поиск, список, импорт/экспорт, горячие клавиши), `initContactsSplits()` — перетаскивание разделителей панелей, `openContacts()` загружает данные и выбирает первый контакт. Код книги не дублировался.
- «Закрыть» (Esc, крестик в карточке) в отдельном окне закрывает само окно; в главном окне оверлейный путь остался рабочим, если понадобится.
- Разметка не менялась: то же окно контактов просто занимает всю клиентскую область под шапкой.

## Сделано

- `src/main.ts` — `openContactsWindow()`, `initContactsWindow()`, `initContactsWindowChrome()`; ветка загрузки `?contacts=1`; `closeContacts()` закрывает окно в режиме окна; кнопка в шапке переведена на окно.
- `src/styles.css` — блок `body.contacts-window`: шапка, ручки, оверлей на всю высоту, карточка без скругления и тени.
