# TASK-020 — отчёт: общие настройки и перевод

## Что сделано
1. Общие настройки (`settings.rs`, `%APPDATA%\Soroka\settings.json`): категории, промпты, подписи.
2. Окно «Настройки» с деревом: Общие (Категории ИИ, Промпты, Подписи) и Ящики; настройки ящика — из контекстного меню ящика.
3. Категории: добавление, переименование, цвет, подсказка для ИИ, правила «отправитель содержит / тема содержит», порядок = приоритет.
4. Промпты: разбор, черновик ответа, улучшение, перевод; плейсхолдеры и сброс к стандартным.
5. Перевод письма: кнопка «Перевести», кэш в таблице `translations`.

## Категории по умолчанию
- Обучение — тема: курс, вебинар, обучени, семинар.
- Партнёр 1С — отправитель: 1c.ru, 1cnw.ru, «1С Информационные письма».
- Клиент, Госорган, Финансы, Уведомление, Реклама, Личное, Осторожно.

## Как это работает
- Правило проверяется до обращения к модели: при совпадении категория ставится детерминированно, модель пишет только сводку.
- Промпт разбора собирается из настроек: `{categories}` и `{categories_hint}` подставляются из списка категорий.
- Цвета бейджей берутся из настроек; старые разборы читаются по прежним названиям.
