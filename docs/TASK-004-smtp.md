# TASK-004 — Отправка писем (SMTP) и редактор

**Цель:** научить «Сороку» отправлять письма: кнопка «Написать», форма (Кому/Тема/Текст),
отправка через SMTP, аккуратные ошибки, живые проверки — письмо самому себе.

**Крейт:** `lettre = "0.11"` (default-фичи: smtp-transport, native-tls, builder, hostname, pool).
Правило проекта: почтовые крейты добавляем ПО ОДНОМУ на задачу.

## Сценарии

1. «Написать» (кнопка или **Ctrl+N**) → форма: Кому, Тема, Текст → «Отправить» (**Ctrl+Enter**)
   → тост «Письмо улетело: адрес»; форма закрывается, поля очищаются.
2. Ошибка отправки (нет сети, неверный адрес, отказ сервера) → тост «Не удалось отправить: …»;
   форма остаётся открытой, приложение живо. Esc / «Отмена» закрывают форму.
3. Валидация: пустой или без «@» адрес получателя → подсказка, отправки нет.
4. Пока идёт отправка — кнопка «Отправляем…» és заблокирована (без двойных отправок).

## Что не входит

- Сохранение в «Отправленные» (IMAP APPEND) — отдельная задача.
- Вложения, HTML-тела, черновики — дальше по плану.
