# TASK-100 — Ресайз окна письма, кнопки за окном, дубли хоткеев, статусбар

Дата: 2026-11-17. Версия: 0.46.50.

## 1. Растягивание окна письма всё ещё медленное

**Почему 0.46.49 не помог.** Ручной ресайз был написан, но до него дело чаще не доходило: окна оставались `resizable: true`, и край окна перехватывал захват системным циклом — тем самым медленным. А когда ручной путь всё же срабатывал, панели на каждом кадре анимировали `flex-grow`/`flex-basis` по 0.22 с — то есть окно не просто меняло размер, а ещё и проигрывало анимацию раскладки.

**Решение.**
- Окна письма и настроек теперь `resizable: false`: системного края нет, размер меняют только наши ручки (перетаскивание по-прежнему через `setPosition`).
- На время растягивания на `body` вешается класс `resizing`, который отключает переходы панелей и выделение текста — раскладка не анимируется.
- Ручки по краям расширены с 5 до 8 px, чтобы попадать без прицеливания.

## 2. Кнопки уезжали за пределы окна

`.compose-actions` и `.sv-actions` были flex-рядами без переноса. Добавлен `flex-wrap: wrap` — на узком окне кнопки переносятся на следующую строку, а не вылезают за край.

## 3. Дубли горячих клавиш

Жили два обработчика: старый `initMailHotkeys` (сравнение по `e.key`, на русской раскладке не работает) и `initMessageHotkeys` (с картой русской раскладки). На латинской раскладке j/k срабатывали дважды — по одному разу на каждый. Старый удалён; действие «r» переведено с `readerCompose()` (он умеет только окно чтения и закрывает свой экземпляр окна) на кнопку панели чтения.

## 4. Статусбар: мёртвые селекторы

Элемент называется `#status-bar`, а CSS использовал `.statusbar` и `#statusbar`. Из-за этого статусбар не перекрашивался в светлой теме и не скрывался в окнах чтения, настроек и редактора. Селекторы исправлены.

## Сделано

- `src/main.ts` — `resizable: false` у окон письма и настроек, класс `resizing`, удалён `initMailHotkeys`, «r» через `replyBtn`.
- `src/styles.css` — `flex-wrap` для футеров, правила `body.resizing`, ручки 8 px, исправлены селекторы статусбара.
