# TASK-017 — Светлая и тёмная тема

## Цель
Дать выбор оформления: тёмная (как была) и светлая. Переключение — кнопками «☀» и «🌙» в шапке окна.

## Требования
1. В шапке — группа из двух кнопок: «☀» (светлая) и «🌙» (тёмная). Активная подсвечена акцентным цветом, у каждой — подсказка при наведении.
2. Выбранная тема сохраняется (`localStorage["soroka.theme"]`) и применяется при следующем запуске.
3. Пока пользователь не выбрал тему явно — берётся системная (`prefers-color-scheme`); при смене системной темы «Сорока» следует за ней.
4. Переключение мгновенное, без перезапуска. В обеих темах читаемы все поверхности: панели, список писем, область чтения, меню, модальные окна (письмо, настройка, календарь, событие), тосты, строка состояния.
5. Окно перекрашивается целиком: Mica/Acrylic и системный заголовок — в тон теме (Rust-команда `set_window_theme`).
6. Контраст: основной текст — не ниже 4.5:1; категории писем, звёздочка важности, счётчики непрочитанных и кнопки различимы на светлом фоне.
7. Лёгкость: переключение не создаёт окон и процессов, не ходит в сеть; память не растёт.

## Реализация
- CSS: единые переменные поверхностей и акцента (`--bg-app`, `--bg-card`, `--bg-elev`, `--bg-scrim`, `--surface1/2`, `--edge`, `--accent-weak/-2/-line`, `--ok/--danger`, `--shadow-menu/-card`), блок переопределений `html[data-theme="light"]`.
- `data-theme` на `<html>`; в `main.ts` — `systemTheme()`, `currentTheme()`, `applyTheme()`, `initTheme()`; кнопки обновляют `aria-pressed`.
- Rust: `set_window_theme(dark)` → `window.set_theme(...)` + `apply_mica/apply_acrylic` в тон.

## Приёмка
- `npm run build`, `cargo test`, `cargo clippy` — без ошибок.
- Скриншоты обеих тем: панель папок, список, чтение, настройка почты, календарь.
- Перезапуск приложения сохраняет выбранную тему.

## Вне задачи
- Сортировка списка и группировка писем — отдельная задача (обсуждается отдельно).
