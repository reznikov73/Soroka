# TASK-111 — Окно контактов: разрешения окна

Дата: 2026-11-17. Версия: 0.46.60.

## Что было

Окно контактов открывалось, но в нём не работало ничего из оконного: ни перетаскивание за шапку, ни растягивание за края, ни закрытие крестиком.

## Причина

Окно создаётся с меткой `contacts-<время>`, а в `src-tauri/capabilities/default.json` список окон был такой:

```json
"windows": ["main", "msg-*", "settings-*", "compose-*"]
```

Tauri в v2 выдаёт разрешения (позиция, размер, закрытие, сворачивание) только окнам, подходящим под шаблон. `contacts-*` в списке не было, поэтому все вызовы `setPosition`, `setSize`, `close`, `minimize` для этого окна отклонялись — молча, через `catch`, поэтому и выглядело как «окно мёртвое», а не как ошибка.

## Решение

Добавлен шаблон `contacts-*`:

```json
"windows": ["main", "msg-*", "settings-*", "compose-*", "contacts-*"]
```

Шапка, ручки и кнопки в окне уже были подключены (TASK-110) — им не хватало только прав.

## Сделано

- `src-tauri/capabilities/default.json` — добавлено окно `contacts-*`.
