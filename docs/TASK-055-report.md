## 2. Как работает склейка папок

- В `src/main.ts` добавлены алиасы: `корзина`, `удалённые`, `удаленные` → «Удалённые». Раньше «Корзина» оставалась отдельной строкой рядом с «Удалёнными».
- При построении дерева папки группируются по отображаемой подписи: в строке остаётся первая папка, счётчики остальных прибавляются к ней.
- Технические `forward` и `sieved` отфильтровываются до построения дерева.
- Операции (открытие, перенос, удаление) работают с реальным серверным именем сохранённой папки — первая из группы становится представителем.

**Ограничение:** вторая папка из пары исчезает из дерева, и её письма нельзя открыть через интерфейс, пока не добавлен выбор внутри строки. Для пустых дублей это незаметно; если у вас в обеих «Отправленных» есть письма — скажите, сделаю раскрытие дублей подстрокой.

## 6. Риски и что не проверено

- **Склейка папок не проверена на живом сервере.** Логика проверена типами и сборкой; на реальных ящиках нужно убедиться, что вторая «Отправленные» действительно пустая.
- **Выбор представителя группы** — первая папка в списке сервера. Если сервер отдаёт «Корзину» раньше «Удалённых», операции пойдут в «Корзину».
- **Визуальная приёмка** контраста и выделения — за вами.
- Пункты из бэклога (иконки, палитра, превью вложений, антифишинг, горячие клавиши, группировка по отправителю) в этот выпуск не входили.
