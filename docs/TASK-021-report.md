# TASK-021 — отчёт: папки, удаление, окно настроек, прозрачность

## Что сделано
1. **Оформление окна** — новая вкладка «Оформление» в настройках. Чекбокс «Прозрачное окно (Mica/Acrylic)». При выключении эффект стекла снимается сразу (`clear_mica`/`clear_acrylic` + `body.opaque`), а окно при следующем запуске создаётся непрозрачным — Rust создаёт окно сам (`"create": false` + `WebviewWindowBuilder` с `transparent` из `settings.json`).
2. **Окно настроек** перемещается за заголовок: pointer events + `transform: translate(...)` вместо `position: fixed` внутри overlay с `backdrop-filter`.
3. **Дерево папок по разделителю сервера**: `FolderInfo.delimiter` из IMAP LIST, колонка `folders.delimiter` в БД (миграция), фронтенд строит дерево по разделителю. `INBOX.Newsletters` у Majordomo — ребёнок «Входящих».
4. **Удаление из списка**: клавиша `Delete` и контекстное меню («Открыть», «В корзину», «Не спам», «Непрочитано/Прочитано»).
5. **Кнопки письма** — отдельным рядом под «От:», по левому краю, с переносом.
