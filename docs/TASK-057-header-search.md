# TASK-057 — слой 2а: глобальный поиск в шапке

Дата: 2026-11-03. Версия: 0.46.10. План: [DESIGN-PLAN.md](DESIGN-PLAN.md).

## 1. Что сделано

- Поле поиска переехало из панели списка в шапку окна: между названием приложения и кнопками, по центру, с максимальной шириной 620 px.
- Кнопки области поиска, обновления, выделения всех и сортировки остались над списком — строка теперь выровнена по правому краю.
- В окнах настроек, письма и редактора поиск скрыт: там шапка своя, а поиск относится только к главному окну.
- Шапка остаётся зоной перетаскивания окна. В обработчике `initWindowDrag` добавлено исключение `.tb-search`, а двойной клик по полю больше не разворачивает окно — иначе клик по строке поиска дёргал бы окно.

## 4. Риски и что проверить

- **Перетаскивание окна** нужно проверить руками: потянуть за пустое место шапки, убедиться, что окно едет; клик по полю поиска не должен двигать окно.
- **Ширина окна.** При минимальной ширине 960 px шапка сжимается: поле поиска имеет минимум 200 px, кнопки не переносятся.
- **Строка над списком** осталась без поля ввода — теперь это только кнопки. Если покажется пусто, можно вернуть туда подпись «Письма» или счётчик.
- **Светлая тема:** поле белое с границей `#e3e7ee`; в тёмной — как у остальных полей.
