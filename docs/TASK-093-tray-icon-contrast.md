# TASK-093 — Иконка трея в тёмной теме

Дата: 2026-11-16. Версия: 0.46.43.

## Постановка

Замечание: «иконка на тёмном фоне не видна».

## Причина

Иконки трея были нарисованы тёмным индиго (средний цвет штриха `(94, 82, 223)`) на прозрачном фоне. На тёмной панели задач Windows такой контур почти сливается с подложкой — точка непрочитанного видна, а сам конверт нет. Проверено по пикселям: `tray.png` — 179 непрозрачных пикселей среднего цвета `(94, 82, 223)`.

## Решение

Двухцветная иконка: светлый конверт `(233, 240, 250)` с тёмным контуром `(12, 18, 30)` по краю штриха. Такой рисунок читается и на тёмной панели (светлый контур), и на светлой (тёмная обводка). Точка непрочитанного — красная с тёмным ободком по той же причине.

Рисуется скриптом в 4× масштабе с уменьшением по Ланцошу — края гладкие, без «лесенки» на 32 px. Файлы перезаписаны теми же именами (`tray.png`, `tray-alert-1.png`, `tray-alert-2.png`), поэтому правок в коде не потребовалось: они зашиты в бинарник через `include_bytes!`.

## Сделано

- `src-tauri/icons/tray.png`, `tray-alert-1.png`, `tray-alert-2.png` — новые двухцветные иконки 32×32.
