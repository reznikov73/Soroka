# TASK-018 — отчёт: сортировка, группировка и одна кнопка темы

## Что сделано
- Переключатель темы стал **одной кнопкой**: она показывает тему, на которую переключит — «☀» в тёмной теме, «🌙» в светлой; подсказка и `aria-label` меняются вместе с иконкой.
- Рядом с поиском появилась кнопка **«⇅»** и меню из двух секций:
  - «Сортировка»: «Сначала новые» (по умолчанию) и «Сначала старые»;
  - «Группировать»: «По датам» (по умолчанию), «По категориям», «Без группировки».
- Выбор сохраняется в `localStorage["soroka.sort"]`, текущие пункты отмечены галочкой, подсказка кнопки описывает текущий режим.
- «По датам»: заголовки «Сегодня», «Вчера», «На этой неделе», «В этом месяце», «Раньше», для неразбираемой даты — «Без даты»; при «Сначала старые» порядок групп обратный.
- «По категориям»: «Важное» (importance = высокая), затем категории ИИ по алфавиту, «Без разбора» — последней.
- У каждой группы — счётчик писем. Заголовки групп не кликаются и не выделяются.
- Сортировка использует настоящую дату письма (`Date.parse` от RFC 2822-строки), а не подпись «16 окт».
- Важные письма больше не поднимаются наверх принудительно: порядок строго по выбранной сортировке, важность отмечена звёздочкой.
