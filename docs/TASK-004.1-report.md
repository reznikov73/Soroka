# TASK-004.1 — Итоговый отчёт (переключение папок)

**Статус:** выполнен; живой прогон со скриншотом. **Дата:** 2026-10-15. **Репозиторий:** https://github.com/reznikov73/Soroka (main).

## Причина

- Список папок в «Сороке» был только для показа: клик по папке ничего не делал, грузился только INBOX.
- Письма, отправленные самому себе, mail.ru складывает в папку `INBOX/ToMyself` (правило ящика) —
  поэтому письма «1111» (10:17 МСК) и «44444444» (10:24 МСК) в «Сороке» было «не найти».
  На сервере оба письма присутствуют — проверено независимым IMAP-сканом.

## Что сделано

- `imap.rs`: `encode_mutf7` — кодирование имени папки в modified UTF-7 (обратное к `decode_mutf7`);
  unit-тест roundtrip + проверка известной строки «Отправленные» ↔ `&BB4EQgQ,BEAEMAQyBDsENQQ9BD0ESwQ1-`.
- Команда `sync_folder(folder)`: загрузка писем любой папки (имя кодируется в mUTF-7).
- UI: папки кликабельны; выбранная подсвечивается; статус «почта: папка «X», писем N»; при ошибке — тост.
- Кэш и офлайн-режим — по-прежнему для INBOX (без изменений).

## Проверка

- fmt / clippy / tsc — чисто; тесты 14/14 (+ `mutf7_roundtrip`), 1 ignored (живой SMTP-тест).
- Живой клик-тест: «INBOX/ToMyself» открывается в приложении, письма «44444444», «1111»,
  «Soroka UI test TASK-004», «Сорока: живой тест SMTP (TASK-004)» видны в списке
  (скриншот `click-tomyself-final.png`); статус «почта: папка «INBOX/ToMyself», писем 10».

## Осталось (кандидаты в следующие задачи)

- Кэширование писем не-INBOX папок (сейчас — только онлайн).
- Счётчики непрочитанных, иерархия дерева папок.
- Сохранение отправленных в «Отправленные» (IMAP APPEND).
