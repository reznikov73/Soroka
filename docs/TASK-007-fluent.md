# TASK-007 — Fluent Design: тёмная тема и акриловое окно

**Цель:** «Сорока» выглядит как родное приложение Windows 11: тёмная тема, полупрозрачное
акриловое окно (Mica на Win11; на нашей Win10 — Acrylic/размытие), системный акцент,
аккуратные карточки и кнопки. **Макеты нарисованы** (заказчик утверждает перед реализацией).

**Макеты:** `.openclaw/tmp/mockups/mock1-main.png` (основной вид), `mock2-reading.png` (чтение),
`mock3-compose.png` (форма «Ответ»). Стиль — Fluent 2: фон #202020, слои rgba(255,255,255,5–10 %),
текст 92/62/42 %, акцент #60cdff, скругления 6–12 px.

## Что меняется

1. **Окно**: `window-vibrancy` — Mica (Win11) → фолбэк Acrylic (Win10) → фолбэк без эффекта;
   скруглённые углы, тонкая рамка.
2. **Своя шапка окна** (системный заголовок убирается): иконка «С», «Сорока — почта»,
   кнопки свернуть/развернуть/закрыть; перетаскивание за шапку (drag region).
3. **Панели**: три колонки-«карточки» (скругление 8 px, тонкие рамки на полупрозрачном слое).
4. **«Написать» переезжает наверх левой колонки** (акцентная кнопка); в футере остаются
   приглушённые «Проверить почту/бэкенд».
5. **Список писем**: карточки с аватарами-буквами, тема жирным, превью серым, время справа,
   выделение — акцентная полоска слева.
6. **Просмотр**: заголовок, отправитель с аватаром, действия (Ответить/Переслать/«Показать
   картинки» — акцентом), тело в карточке, чипы вложений, UID мелким серым.
7. **Формы** (письмо/ответ/пересылка): акриловая модалка с блюром фона, поля с подсветкой
   фокуса акцентом, кнопки Fluent (primary — акцент).
8. **Тёмные мелочи**: тосты, скроллбары (`color-scheme: dark`), hover/selected состояния.
