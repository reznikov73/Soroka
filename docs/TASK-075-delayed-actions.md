# TASK-075 - Отложенные действия как настройка

Дата: 2026-11-12. Версия: 0.46.31.

## Постановка

Удаление писем выполняется с задержкой 7 секунд и тостом «Отменить». На практике отмена почти не нужна — лишняя пауза. Просьба: сделать отложенные действия настраиваемой опцией.

Решения пользователя:

- По умолчанию (новая установка и старые настройки) — мгновенные действия, без отмены.
- Одна опция на все три отложенных действия: удаление в корзину, «В спам», отправка письма.
- Перед началом работы закоммитить накопленные TASK-073/074 (сделано отдельным коммитом `1cfef93`).

## Решения

- Поле названо `delayed_actions`, а не `delayed_delete`: опция управляет всеми тремя действиями.
- Значение по умолчанию `false`: у существующих пользователей (в файле настроек поля нет) действия станут мгновенными — это и есть просьба. Тем, кому нужна отмена, — включить чекбокс.
- Окно чтения письма (`readerMove`) не тронуто: оно и так переносит письма сразу, без очереди.
- Отправка: общий код вынесен в `doSend`, очередь (`flushSend`) и мгновенный путь (`doSend` напрямую) используют его; логика ошибок и возврата в редактор не изменилась.

## Сделано

- `src-tauri/src/settings.rs` — поле `delayed_actions` в `UiSettings` (`serde(default)`), значение по умолчанию `false`, тест на старые настройки без поля.
- `src/main.ts`:
  - `UiSettingsData.delayed_actions?`;
  - хелпер `delayedActionsEnabled()`;
  - `requestDelete`: при выключенной опции — сразу `commitDelete`, без таймера и тоста «Отменить»;
  - `requestSpam`: аналогично — сразу `commitSpam`;
  - `queueSend`: при выключенной опции — сразу `doSend`; общий код отправки вынесен в `doSend`;
  - `renderAppearance` и обработчик `opt-delayed` — чтение и запись чекбокса.
- `index.html` — чекбокс «Отложенные действия с отменой…» в разделе «Оформление», рядом с трее­ем и автозапуском.
- Версия `0.46.31` в `tauri.conf.json`, `Cargo.toml`, `package.json` (через `scripts/sync-version.ps1`); раздел в `CHANGELOG.md`.
