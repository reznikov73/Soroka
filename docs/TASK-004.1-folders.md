# TASK-004.1 — Переключение папок (видно письма из любой папки)

**Проблема:** список папок в «Сороке» был только для показа — клик по папке ничего не делал,
загружался только INBOX. Из-за правила mail.ru (письма «от себя» → `INBOX/ToMyself`) отправленные
себе письма «пропадали» для пользователя.

**Цель:** клик по папке слева загружает её содержимое; понятные статус и ошибки.

## DoD

- [ ] `imap.rs`: `encode_mutf7` (обратное к `decode_mutf7`) + тесты (roundtrip; «Отправленные» ==
      наблюдаемая строка `&BB4EQgQ,BEAEMAQyBDsENQQ9BD0ESwQ1-`; обработка `&`).
- [ ] Команда `sync_folder(folder)` — загрузка писем любой папки (имя кодируется в mUTF-7).
- [ ] UI: папки кликабельны; выбранная подсвечена; статус «почта: папка «X», писем N»; ошибка — тост.
- [ ] Кэш/офлайн остаются для INBOX (без изменений).
- [ ] fmt/clippy/tsc чисто; тесты; живой прогон: клик по `INBOX/ToMyself` показывает письма
      «1111», «44444444».
- [ ] Версия 0.4.1, changelog, readme, отчёт, тег `v0.4.1`, релиз.
