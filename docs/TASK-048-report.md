# TASK-048 — окно письма по варианту 1

Версия: 0.45.0. Дата: 22.10.2026.

## Что сделано
- В отдельном окне появилась своя панель действий: «‹»/«›» (навигация по письмам папки), «Ответить», «Ответить всем», «Переслать», «В папку…» (список папок), «Удалить», «Спам», «Непрочитано», «Печать».
- «Ответить всем» собирает отправителя, To и Cc через message_recipients, исключает собственный адрес и открывает редактор в главном окне.
- «Удалить»/«Спам»/«В папку» переносят письмо через move_messages и показывают следующее письмо, если оно есть.
- Навигация Alt+↑ / Alt+↓; Esc закрывает окно.
- Размер окна запоминается в localStorage (soroka.readerGeom) и применяется при следующем открытии.
- Системный второй заголовок убран (decorations:false), остался один заголовок.

## Проверка
- npm run build — ok; cargo tauri build — ok; exe 7.50 МБ, установщик 2.85 МБ.
- Живой снимок окна с новой панелью сделать не удалось: в момент проверки фокус перехватывал 1С, а двойной клик по строке не выделял письмо (окно перекрыто). Код собран, визуальная проверка панели остаётся за пользователем.

## Ограничения
- «Печать» использует системный диалог WebView2 без отдельного print-CSS: может печатать интерфейс окна.
- В окне нет «+ В книгу», «Перевести», «Разбор» — эти действия остаются в главном окне.
- Позиция окна не запоминается, только размер.
