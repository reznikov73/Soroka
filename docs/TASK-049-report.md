# TASK-049 — настройки, трей, резервные копии, окна

Версия: 0.46.0. Дата: 26.10.2026.

## Что сделано
1. Кнопка «+ Категория» разведена с крестиком: у шапки раздела зарезервировано 44 px справа.
2. Опция трея переименована в «Сворачивать в трей при сворачивании и закрытии». Крестик и Alt+F4 прячут окно в трей; полный выход остаётся в меню трея, очистка корзины выполняется только при настоящем выходе.
3. Чтение письма не удаляет его с сервера: тело загружается через BODY.PEEK, затем отдельно ставится флаг \Seen. Удаление только по команде пользователя.
4. Раздел «Данные»: пути к настройкам, логам и папке программы, кнопки «Открыть» через системный Проводник.
5. Полная резервная копия: tar-архив в «Документы\POS Mail Backups» с settings.json, accounts.json, gigachat.json, window.json и soroka.db. Восстановление распаковывается в restore-pending и применяется до открытия базы при следующем запуске.
6. Настройки, редактор письма и окно письма открываются отдельными окнами с нативным заголовком Windows (свернуть, развернуть, закрыть, переместить, изменить размер). Главное окно сохраняет фирменный заголовок.
