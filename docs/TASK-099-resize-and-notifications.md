# TASK-099 — Быстрое растягивание окон и отключение уведомлений

Дата: 2026-11-17. Версия: 0.46.49.

## 1. Растягивание окна письма медленное

**Причина.** Изменение размера шло через `startResizeDragging` — это тот же системный модальный цикл Windows, из-за которого медленно тянулись окна до TASK-081. Перетаскивание мы тогда заменили ручным, а растягивание оставили нативным, и оно осталось медленным.

**Решение.** Растягивание теперь тоже ручное: на `pointerdown` запоминаем позицию и размер, на каждом `pointermove` считаем новый прямоугольник и ставим его **раз в кадр** через `setSize`, а для левого и верхнего краёв ещё и `setPosition` (иначе окно «растёт» в одну сторону). Размер ограничен минимальным (620×460 для письма, 760×520 для настроек) с учётом масштаба экрана. Общая функция `addResizeHandles(win, minW, minH)` работает в обоих окнах без системной рамки.

## 2. Уведомления нельзя отключить

**Решение.** Новая настройка `ui.notifications` (по умолчанию включена) и чекбокс «Показывать уведомления о новых письмах» в разделе «Оформление» рядом с IDLE. Бэкенд проверяет настройку перед показом тоста — то есть выключение действует сразу, без перезапуска.
