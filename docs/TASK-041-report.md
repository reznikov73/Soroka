# TASK-041 — ключ GigaChat в настройках

Версия: **0.38.0**. Дата: 2026-10-21.

## Проблема
Ключ GigaChat можно было задать только вручную: положить `%APPDATA%\Soroka\gigachat.json` или выставить `SOROKA_GIGACHAT_KEY`. В интерфейсе не было ни ввода, ни проверки, ни индикации — человек не понимал, работает ИИ или нет.

## Решение
Новый раздел настроек **«ИИ (GigaChat)»**:
- поле ключа авторизации с маскировкой и переключателем «Показать ключ»;
- кнопка **«Сохранить ключ»** — пишет `%APPDATA%\Soroka\gigachat.json` (`{"api_key": "…"}`), сбрасывает кэш OAuth-токена;
- кнопка **«Проверить подключение»** — получает токен GigaChat (OAuth `ngw.devices.sberbank.ru`), не расходуя токены модели, и показывает «Ключ рабочий: токен получен» либо текст ошибки;
- кнопка **«Удалить ключ»** — удаляет файл и кэш токена;
- строка состояния говорит, откуда взят ключ: файл / переменная окружения / не задан.

Ключ никогда не отдаётся обратно в интерфейс: команда `gigachat_status` возвращает только источник (`env`/`file`/`none`), а не значение. Переменная окружения по-прежнему важнее файла.

## Реализация
- `ai/gigachat.rs`: `key_path`, `key_status`, `save_api_key`, `clear_api_key`, `reset_token`, `check_api_key`; `KeyStatus` без поля с ключом.
- `commands/mod.rs`: `gigachat_status`, `save_gigachat_key`, `clear_gigachat_key`, `check_gigachat_key`; зарегистрированы в `lib.rs`.
- `index.html` / `main.ts`: раздел `view-ai`, `renderAiSettings`, обработчики; навигация по настройкам.

## Проверка
- `npm run build` — ok; `cargo clippy --all-targets -- -D warnings` — чисто; `cargo tauri build` — ok.
- Вживую: экран открывается, статус показывает «Ключ сохранён в файле» (у пользователя уже был `gigachat.json`), кнопка «Проверить подключение» вернула **«Ключ рабочий: токен получен»**. Скриншоты `p0380-2-gigachat.png`, `p0380-3-check.png`.
- Не проверял: сохранение нового (другого) ключа — не стал затирать рабочий ключ пользователя; логика записи и удаления покрыта кодом и использует тот же файл.

## Возможные следующие шаги
- Шифровать ключ через DPAPI (сейчас файл в открытом виде, как и `accounts.json`).
- Выбор модели (GigaChat / GigaChat-Pro) и температуры в этом же разделе.
- Кнопка «Проверить» для каждого ящика отдельно.
