# TASK-044 — цитата, отдельное окно письма, компоновка

Версия: 0.40.4. Дата: 22.10.2026.

## Что сделано
- Цитата в HTML-письмах: блок `--- Исходное письмо ---` переносится в `<details class="quote">` с подписью «Показать цитату · N строк». В текстовых письмах маркер распознаётся в любом месте, в том числе в начале.
- Отдельное окно: двойной клик по строке и пункт «Открыть» создают окно Tauri 980x760 с заголовком, отправителем, датой, телом, вложениями и свёрнутой цитатой. Панели, навигация и статусная строка скрыты.
- Двойной клик определяется вручную по UID и интервалу 420 мс, потому что после первого клика список перерисовывается и браузерный dblclick не срабатывает. В «Черновиках» двойной клик открывает редактор.
- Компоновка: панель папок 238 px, синяя полоса у непрочитанных, отправитель 12.6 px, время 11 px, отступы папок 5/8/22, фон приложения #f7f8fa.
