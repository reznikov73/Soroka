# TASK-066 — иконки из макета

Дата: 2026-11-04. Версия: 0.46.18.

## Почему были видны старые иконки

Пользователь запускал сборку 0.46.16 из `src-tauri/target/release`, а правки 0.46.17 лежали в `target-build`. Плюс сама звезда в 0.46.17 была текстовым глифом ☆/★ — в некоторых шрифтах он выглядит как флажок. Теперь звезда — SVG.

## Что сделано

**Иконки взяты напрямую из `pos-mail-redesign.html`** — те же `d`-пути, `viewBox="0 0 24 24"`, обводка 2:

- папки: входящие, спам, черновики, отправленные, корзина, архив, рассылки, папка по умолчанию;
- шапка: тема, календарь, адресная книга, настройки, раскладка;
- звезда в строке списка: `polygon` из макета; у важного письма залита `currentColor` и подсвечена янтарным `#f59e0b`.
