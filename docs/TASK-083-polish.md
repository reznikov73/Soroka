# TASK-083/084/085 — Полировка: снап по Shift, подсказки клавиш, скелетон списка

Дата: 2026-11-14. Версия: 0.46.37.

## Постановка

Три мелких пункта дорожной карты, которые не тянут отдельные релизы:

- после перехода на ручное перетаскивание (TASK-081) пропало примагничивание окна к краям экрана;
- горячие клавиши (TASK-080) работают, но узнать о них можно было только из changelog;
- при переключении папки список на мгновение пустеет — выглядит как «ничего не нашлось».

## Решения

- **TASK-083, снап.** `Shift` + перетаскивание заголовка отдаёт перемещение системе (`startDragging`): медленнее, зато с примагничиванием. Обычное перетаскивание остаётся ручным и быстрым.
- **TASK-084, подсказки.** Клавиши упомянуты там, где пользователь и так смотрит: в подсказке заголовка «Письма», в плейсхолдере поиска (`( / )`) и у кнопки проверки почты (`(u)`). Отдельный экран помощи не делали — лишний модальный слой ради справки.
- **TASK-085, скелетон.** Если папка грузится дольше 160 мс, вместо пустоты показываются 7 серых строк-заготовок. Пульсирует только `opacity` — без пересчёта лэйаута. Как только приходят данные, `renderMessages()` убирает заготовку; при ошибке загрузки — тоже.

## Сделано

- `src/main.ts` — `Shift`-ветка в `enableWindowDrag()`, `scheduleSkeleton()`/`clearSkeleton()`, подсказка у заголовка списка.
- `src/styles.css` — `.sk-row`, `.sk-line`, `@keyframes sk-pulse`.
- `index.html` — плейсхолдер поиска и подсказка кнопки проверки почты.
