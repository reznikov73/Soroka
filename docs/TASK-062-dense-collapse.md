# TASK-062 — свёрнутые группы в плотном режиме

Дата: 2026-11-04. Версия: 0.46.15.

## 1. Причина

Строки свёрнутой группы скрываются атрибутом `hidden`, для которого есть правило:

```css
#messages li.m-row[hidden] { display: none; }   /* styles.css:688 */
```

Но правила плотного режима задают `display: flex` и специфичнее по числу классов:

```css
body.dense-list #messages li.m-row { display: flex; ... }
```

Специфичность: `(1,2,1)` у `[hidden]` против `(1,2,2)` у плотной строки — плотное правило выигрывало, `display: none` не применялся, и письма свёрнутой группы оставались на экране.

## 2. Исправление

```css
body.dense-list #messages li.m-row[hidden] { display: none; }
```

Специфичность `(1,3,2)` — выше плотного правила, скрытие работает в обеих темах. Обычный режим не затронут: там `[hidden]` и раньше выигрывал.
