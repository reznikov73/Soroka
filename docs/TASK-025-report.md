# TASK-025 — отчёт: массовое выделение писем и файловые логи

## 1. Массовое выделение писем

- **Ctrl+клик** — добавить/убрать одно письмо, **Shift+клик** — выделить диапазон от последнего выбранного по видимому порядку строк; обычный клик сбрасывает выделение и открывает письмо.
- Выделенные строки подсвечиваются, над списком появляется панель «Выбрано: N» с кнопками:
  - «🗑 В корзину» — переносит все выбранные письма **одним IMAP-соединением** (`UID MOVE` набором), локальный кэш и `MailState` обновляются;
  - «Прочитано» / «Непрочитано» — один `UID STORE +FLAGS/-FLAGS (\Seen)`;
  - «⚑» / «Снять ⚑» — `UID STORE (\Flagged)`;
  - «✕» — снять выделение.
- При смене папки выделение сбрасывается.
- Backend: `imap::move_many_to_trash`, `imap::set_seen_many`, `imap::set_flagged_many`, команды `delete_messages`, `mark_messages_seen`, `mark_messages_flagged`.
