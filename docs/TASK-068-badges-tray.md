# TASK-068 — без всплывающих кнопок, маркировка по настройке, трей

Дата: 2026-11-05. Версия: 0.46.20.

## 1. Всплывающие кнопки над строкой

Убраны полностью: `.m-actions` больше не показывается (`display: none`), а время строки перестало исчезать при наведении. Ответ, отметка прочтения и удаление остаются в панели чтения, в массовой панели и на клавиатуре — дублировать их поверх строки больше не нужно.

## 2. Маркировка категории в строке

Раньше бейдж показывался всегда, если у письма есть разбор. Теперь:

- при группировке **по категориям** бейдж не показывается — категория уже написана в заголовке группы;
- при группировке по датам и без группировки бейдж показывается, но только если включена новая опция **«Отображать маркировку письма в заголовке»** (Настройки → Оформление, по умолчанию включена).

В настройках добавлено поле `show_badge` (по умолчанию `true`); старые файлы настроек без поля читаются как включённые.

## 3. Сворачивание в трей

Обработчик кнопки «свернуть» был на месте и читал `minimize_to_tray` из настроек; если `hide()` возвращал ошибку, она молча проглатывалась. Теперь ошибка показывается сообщением «Не удалось свернуть в трей: …», чтобы причина была видна.

Если после обновления окно всё равно уходит в панель задач, а не в трей — значит, скрытие отклоняет сама Windows/оболочка, и сообщение об этом появится на экране.
