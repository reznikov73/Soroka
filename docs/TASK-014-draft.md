# TASK-014 — Черновик ответа «в моём стиле»

**Статус:** выполнен. **Дата:** 2026-10-18. **Репозиторий:** https://github.com/reznikov73/Soroka

## Цель
ИИ предлагает черновик ответа на письмо, написанный в стиле владельца ящика; человек правит и отправляет сам. Ничего не уходит без подтверждения.

## Требования
1. Кнопка «✍ Черновик» в шапке открытого письма.
2. Образцы стиля — последние письма из «Отправленные» (до 4 непустых, ≥20 символов; тестовые не берём).
3. Черновик: приветствие, суть ответа; без markdown; без подписей-заглушек и «разделителей».
4. Открывается форма ответа: «Кому» = автор письма, «Тема» = «Re: …», текст = черновик; отправка — вручную.
5. Ошибки — понятным тостом.

## Реализация
- Rust `ai/gigachat.rs`: `draft()` (temperature 0.4, max_tokens 700), `build_samples()`, `build_draft_prompt()`, `clean_draft()` (разделители, заглушки «ваше имя», хвост «С уважением,»).
- Rust `commands::draft_reply(folder, uid, subject, from)` — тело письма из кэша/IMAP, образцы из «Отправленных», вызов GigaChat.
- UI: `#draft-btn`, `requestDraftReply()` → `openCompose({title, to, subject, body})`.

## Проверки
- `cargo test` — 44 passed, 1 ignored; clippy чистый; `npm run build`.
- Живой тест: письмо «встреча» → «✍ Черновик» → форма с адресом/темой/текстом (ui14-2, ui14-7).

## Ограничения
- Стиль зависит от накопленных «Отправленных» (в новом ящике образцов мало); модель может ошибиться в деталях — обязательна проверка человеком.
