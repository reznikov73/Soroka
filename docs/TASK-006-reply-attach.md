# TASK-006 — Ответ/пересылка, вложения, «Показать картинки»

**Цель:** превратить «Сороку» в рабочий инструмент переписки:
- ответ и пересылка письма из просмотра (с цитатой исходного);
- вложения: входящие (список + сохранение) и исходящие (прикрепить файлы при отправке);
- кнопка «Показать картинки» для конкретного письма (дефолт приватности не меняется).

**Новые крейты:** нет — всё на lettre/mail-parser/base64, которые уже в проекте.

## Поведение

1. **«Показать картинки».** По умолчанию внешние картинки не грузятся: блокировка теперь на уровне
   рендера (CSP в iframe: `default-src 'none'; img-src data:`), а санитизация при хранении src не вырезает.
   Кнопка видна, если в письме есть `<img src>`. Клик — перерисовка с разрешением картинок только этого
   просмотра; при повторном открытии письма — снова скрыты (максимальная приватность по умолчанию).
2. **Входящие вложения.** Под телом письма — чипы «📎 имя (размер)». Клик — сохранение в
   `%USERPROFILE%\Downloads` (уникальное имя, санитизация имени), тост с путём. Без сети — понятная ошибка.
   Метаданные вложений кэшируются в `bodies.attachments` (JSON). Inline-картинки (cid:) в список не попадают (позже).
3. **Ответ.** Кнопка «Ответить» → форма с полями: Кому = адрес отправителя, Тема = «Re: …»,
   внизу — цитата (текст письма + строка «--- Исходное письмо ---»). **Пересылка** — пустой Кому, «Fwd: …», цитата.
4. **Вложения при отправке.** Кнопка «Прикрепить файлы» (input[type=file], multiple) → список с размерами
   и удалением; лимиты ≤ 15 МБ/файл и ≤ 20 МБ суммарно. Отправка — multipart/mixed (текст + файлы).
