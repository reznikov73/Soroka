# TASK-046 — выделение, кнопки, ящики, счётчики, окно письма

Версия: 0.42.1. Дата: 22.10.2026.

## Что сделано
1. Множественное выделение: строки получают синий фон (#d9e6fb) и полосу слева; Delete отправляет в корзину все выделенные письма (`requestDelete([...selectedUids])`), а не только текущее.
2. Кнопки письма в едином стиле (27 px, рамка #cfd6df, радиус 7); «Ответить» — акцентная. В «⋯» остались только «+ В книгу», «Непрочитано», «Перевести»; «Черновик», «Показать картинки», «Разбор», «В корзину» всегда на виду.
3. Панель ящиков: несколько ящиков можно раскрыть треугольником; состояние хранится в `localStorage` (`soroka.expandedAccounts.v2`) и восстанавливается между сессиями. Активный ящик раскрыт всегда, остальные — по выбору.
4. Счётчики: у ящиков и папок формат «непрочитано / всего», например «0 / 2»; непрочитанные слева, всего справа.
5. Панель ящиков по макету: плоские строки без карточек, цветная полоса ящика, компактные отступы, линейные SVG-иконки папок, синее выделение выбранной папки, счётчики в правых колонках.
6. Окно письма: `decorations: false` — убран второй системный заголовок; добавлены работающие «Ответить», «Переслать», «Показать картинки». Ответ/пересылка отправляют событие `reader-action` в главное окно и открывают редактор там.

- Окно письма 0.42.1: открытие и новые кнопки не успел снять — приложение закрыли во время проверки. Код `decorations:false` и обработчики `reader-action` собраны, но снимка нет.
- Ответ из окна письма: событие и открытие редактора в главном окне не проверены вживую.

## Ограничения
- В окне письма доступны только «Ответить», «Переслать», «Показать картинки»; остальные действия скрыты.
- Счётчики папок показывают 0 / 0 для пустых или ещё не синхронизированных папок.
