# TASK-033 — вложения 2.0 и эргономика P1/P2

Версия: **0.30.0**. Дата: 2026-10-20. Объём: 12 файлов, +~900 строк.

## Что сделано

### 1. Вложения (P1)
- `renderAttachments` переписан: строка «Вложения · N · общий размер», кнопка «Сохранить все» (при N ≥ 2).
- Чип: инлайновая SVG-скрепка, имя с обрезкой, размер, кнопки «↓» и «⋯»; состояния `saving`/`saved`.
- Для картинок — до трёх карточек с миниатюрой (`attachment_preview` → data URL, лимит 4 МБ на картинку), остальные чипами.
- Контекстное меню: Открыть, Сохранить в «Загрузки», Копировать имя файла, Показать в папке, Сохранить все (N).
- Клик по чипу открывает файл (при необходимости сначала сохраняет).
- Бэкенд: `body::save_all_attachments_to_downloads`, `body::attachment_data_url`, команды `save_all_attachments`, `attachment_preview`, `open_path`, `reveal_path` (через `explorer`, без новых крейтов).

### 2. Перетаскивание и вставка в письме (P1)
- `addComposeFiles(files)` — общий путь для кнопки «Прикрепить файлы», drag&drop и Ctrl+V.
- Оверлей-подсказка «Отпустите файлы — прикреплю их к письму».
- В `tauri.conf.json` окна выставлено `"dragDropEnabled": false`, чтобы WebView2 не перехватывал файловые drop-события.

### 3. Действия при наведении (P2)
- В строке письма при наведении: «прочитано/непрочитано», «важное», «в корзину» (иконки SVG, `stopPropagation`, у `.m-time` на время наведения `visibility: hidden`).

### 4. Удаление с отменой (P2)
- `requestDelete` / `undoDelete` / `commitDelete`: письмо помечается `pending-del`, в тост выводится «Отменить», перенос в корзину выполняется через 7 секунд; отмена снимает таймер и возвращает строки. Кликом по любому месту тоста тоже можно отменить.
- `window.confirm` при одиночном и массовом удалении убран; для «Очистить корзину» оставлен.

### 5. Поиск (P2)
- Переключатель «в папке / везде» рядом с полем поиска.
- «Везде»: `Store::search_messages(prefix, query, limit)` по кэшу всех папок ящика + команда `search_messages`. Сравнение в Rust через `to_lowercase` (SQLite `LOWER()` не понимает кириллицу — иначе «Тест» не находится по «тест»).
- В результатах видна папка, совпадения в теме и отправителе подсвечиваются `<mark>`.

### 6. Клавиши в письме (P2)
- `Ctrl+Enter` — отправить (было), `Esc` — сохранить черновик и закрыть (было), добавлен `Ctrl+S` — сохранить черновик с тостом.

## Замечания
- Найденные и исправленные по ходу дефекты: `LOWER()` в SQLite не работает с кириллицей; `.toast { display: flex }` перебивал `.hidden` (тост не скрывался) — добавлено `.toast.hidden { display: none }`; меню области поиска было растянуто на всю ширину из-за `.dd-menu { left:0; right:0 }`.
- Размер: exe 7.16 МБ, установщик 2.65 МБ. Замер памяти в этом релизе не показателен: на машине висели осиротевшие процессы WebView2.
