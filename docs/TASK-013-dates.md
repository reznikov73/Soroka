# TASK-013 — Задачи и даты из писем → календарь (.ics)

**Цель:** в карточке «✦ Разбор» показывать даты и задачи из письма и давать сохранить их в календарь файлом `.ics` («Сорока» сама ничего не отправляет — только готовит файл, он открывается двойным щелчком).

## Часть A. Показ (карточка «Разбор»)

- Под сводкой — блок дат: разобранные даты → акцентные чипы «📅 17 окт – 18 окт», «📅 15 ноя · срок», «📅 17 окт, 10:30» (клик = сохранить .ics).
- Неразобранные даты → серые чипы без действия (например, «код устареет через 5 минут»).
- Ниже — блок задач: строки «• текст»; у задач, в которых встречается дата, справа кнопка «📅».

## Часть B. Разбор дат (клиент)

Форматы: `DD.MM.YYYY`/`DD.MM.YY`, `DD-MM-YYYY`, `MM/DD/YYYY` (англ. письма), `DD-DD месяц`, `с DD по DD месяц`, `до DD месяц` («· срок»), `DD месяц [YYYY]`, «сегодня/завтра/послезавтра [в HH:MM]», диапазоны через «-», несколько дат через «;» (каждая — отдельным событием). Без года — текущий (давно прошедшая дата → следующий год). Неразобранное не выдумываем.

## Часть C. Экспорт (Rust, `ics.rs`)

- `build_ics`: RFC 5545 — `DTSTART;VALUE=DATE` / `DTSTART:…T…`, CRLF, экранирование `\ ; ,` и переводов строк, UID v4 + DTSTAMP (без внешних крейтов), `METHOD:PUBLISH`.
- Команда `export_event_ics(title, start, end, description)`; файл «Сорока событие ДД.ММ.ГГГГ.ics» в «Загрузки» (+ « (N)» при совпадении); тост с именем файла.
- Контекст — в DESCRIPTION (тема, отправитель, исходная фраза).

## Проверки

`cargo test` — юниты: весь день / время / экранирование / отказ на мусор / конвертация дней / имя файла; `npm run build` — чисто; живой тест: письмо → чип → файл в «Загрузках» (проверить содержимое).

## Этапы

1. Rust `ics.rs` + команда + TS-разбор/показ — commit.
2. Живой тест; далее — по отзывам.

## Часть D. Календарь планов (по замечанию пользователя)

- Кнопка «Календарь» в шапке окна открывает экран календаря (почта скрывается; кнопка превращается в «Почта», Esc — назад).
- Месячная сетка (недели с понедельника): день с событиями — до 3 чипов («10:30 название») + «+N ещё»; «сегодня» — акцент, выбранный день — рамка.
- Справа — список выбранного дня: время / название / источник (письмо); кнопки «Открыть письмо» и «Сохранить .ics».
- Данные — все разборы из БД (`get_calendar_entries`: папки, тема из INBOX-кэша); события строятся тем же парсером дат (даты + задачи с датами, диапазоны раскладываются по дням).
- «Сегодня» + стрелки месяцев.
- Тост сохранения .ics переформулирован: «📅 Файл в «Загрузках»: <имя> — двойной щелчок добавит событие в календарь».
