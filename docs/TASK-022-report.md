# TASK-022 — отчёт: черновики

## Что сделано
1. **Кнопка «В черновики»** в окне письма + индикатор «✓ сохранено ЧЧ:ММ».
2. **Автосохранение каждые 20 секунд**, пока окно письма открыто; повторно не сохраняет, если ничего не изменилось.
3. **Папка `\Drafts`** определяется по флагу IMAP LIST (фолбэк — имя «Drafts»/«Черновики»); сохранение через IMAP `APPEND` с флагом `\Draft`, UID берётся из APPENDUID либо поиском по заголовку `X-Soroka-Draft`.
4. **Двойной клик по черновику** в списке открывает окно письма с заполненными полями (локальная копия в таблице `drafts`).
5. **После отправки** черновик удаляется с сервера (`\Deleted` + EXPUNGE) и из кэша.
6. Схема БД: таблица `drafts`; в `folders` добавлена колонка `is_drafts` (миграция).

## Важно: инцидент при проверке
При попытке открыть окно письма координаты клика не совпали с новой раскладкой окна: нажатие попало на кнопку «Очистить корзину», и 6 писем из корзины были удалены безвозвратно (IMAP EXPUNGE). Восстановить их нельзя. Ранее, при проверке 0.21.0, клик также попал в интерфейс и переместил письмо в корзину.
GUI-проверки остановлены, чтобы не трогать данные пользователя.

## Не проверено
