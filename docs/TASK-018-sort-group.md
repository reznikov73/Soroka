# TASK-018 — сортировка и группировка списка писем

## Цель
Дать управляемый порядок в списке писем: сортировка по дате и группировка по датам или категориям, плюс одна кнопка переключения темы.

## Требования
1. Тема: одна кнопка в шапке. Показывает тему, на которую переключит: из тёмной — «☀» (светлая), из светлой — «🌙» (тёмная). Подсказка и `aria-label` меняются.
2. Кнопка «⇅» рядом с полем поиска открывает меню:
   - «Сортировка»: «Сначала новые» (по умолчанию), «Сначала старые»;
   - «Группировать»: «По датам» (по умолчанию), «По категориям», «Без группировки».
3. Выбор сохраняется (`localStorage["soroka.sort"]`) и применяется при следующем запуске; текущий пункт отмечен галочкой.
4. Группировка «По датам»: заголовки «Сегодня», «Вчера», «На этой неделе», «В этом месяце», «Раньше», для писем без разбираемой даты — «Без даты». При сортировке «Сначала старые» порядок групп обратный.
5. Группировка «По категориям»: «Важное» (importance = высокая), затем категории ИИ по алфавиту, «Без разбора» — последней.
6. У каждой группы — счётчик писем. Заголовок группы не кликабелен и не выделяется.
7. Поиск работает вместе с порядком: сначала фильтрация, затем сортировка и группировка.
8. Сортировка по дате использует настоящую дату письма (`Date.parse` от RFC 2822-строки из IMAP), а не отформатированную подпись.

## Реализация
- `src/main.ts`: `sortState` (`order`, `group`), `loadSortState/saveSortState`, `messageTime`, `dateGroupLabel`, `categoryGroupLabel`, `groupTitles`, `sortedMessages`, `messageRow`, `renderMessages`, `initSortMenu`.
- `index.html`: одна кнопка `#theme-btn`, строка поиска с `#sort-wrap` и меню `#sort-menu`.
- `src/styles.css`: стили кнопки темы, кнопки «⇅», меню и заголовков групп.

## Приёмка
- `npm run build`, `cargo test`, `cargo clippy` — без ошибок.
- Скриншоты: меню сортировки, группировка по датам, группировка по категориям, «без группировки», одна кнопка темы в обеих темах.
- Перезапуск сохраняет выбранные сортировку и группировку.

## Вне задачи
- Группировка по отправителю (цепочки) — не входит.
