# TASK-097 — Кнопка добавления ящика, удаление, показ пароля, окно письма

Дата: 2026-11-17. Версия: 0.46.47.

## Постановка

Пять замечаний: кнопка «Добавить ящик» на главном окне перестала работать; не подключается ящик Яндекса; нельзя удалить ящик; хочется посмотреть и скопировать пароль; окно письма перемещается медленно.

## Решения

**Кнопка на главном окне.** В TASK-095 я скрыл её классом `hidden`, чтобы «перенести» в настройки. Получилось хуже: на главном окне она пропала. Вернул: кнопка снова видна и работает, кнопка в настройках осталась. Две точки входа — это нормально.

**Удаление ящика.** Новая команда `delete_account`: убирает запись из `accounts.json` и возвращает оставшийся список. В форме ящика появилась кнопка «Удалить ящик» (видна только для существующего ящика), удаление в два нажатия — первое меняет подпись на «Точно удалить?» и через 4 секунды откатывается, второго нажатия достаточно. После удаления главное окно перечитывает список и, если активный ящик исчез, переключается на первый оставшийся.

**Показ и копирование пароля.** В поле пароля появились две кнопки: «👁» переключает `type` между `password` и `text`, «⧉» копирует значение в буфер. Копирование через `navigator.clipboard`; если WebView не разрешил — тост подсказывает показать пароль и скопировать вручную.

**Ошибка входа у Яндекса.** Сообщение «[AUTHENTICATIONFAILED] LOGIN invalid credentials or IMAP is disabled» теперь дополняется подсказкой по домену: для Яндекса — включить IMAP в настройках Почты и взять пароль приложения из 16 символов; для Gmail — пароль приложения; для Mail.ru — включить IMAP/SMTP и создать пароль для внешнего приложения. Сам текст ошибки сохраняется, чтобы было видно ответ сервера.

**Окно письма.** Оно создавалось с `decorations: true`, то есть с системной рамкой: сверху рисовался ещё и штатный заголовок Windows, а перемещение шло через системный цикл — тем самым медленным путём, который мы убрали у главного окна и настроек в TASK-081. Теперь окно письма тоже без рамки: своя шапка с кнопками, ручное перетаскивание через pointer capture и `setPosition` раз в кадр.

## Сделано

## Осталось

- Ящик Яндекса: причина отказа — на стороне сервера. Пароли приложений Яндекса — 16 символов; строка из 32 hex-символов на них не похожа (скорее это секрет OAuth-приложения). Нужно: включить IMAP в настройках Почты и создать пароль приложения на id.yandex.ru → Безопасность → Пароли приложений.
- Кэш удалённого ящика остаётся в базе (`folder_keys` вида `id::ПАПКА`) — на работу не влияет, но при желании добавим очистку.
