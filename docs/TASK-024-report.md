# TASK-024 — отчёт: адресная книга, автодополнение и порядок в списке

## Что сделано

### 1. Скрепка
Эмодзи 📎 заменено на тонкую SVG-скрепку 13×13, цвет — синеватый акцент (`var(--accent)`), выравнивание по тексту. Видна в строке списка у писем с вложениями.

### 2. Стрелки в списке
Причина «хаотичности»: стрелки ходили по массиву, отсортированному по дате, а на экране список сгруппирован (важное, категории), поэтому визуальный порядок другой.
Теперь `moveMessageSelection()` берёт **видимые строки DOM** (`#messages li.m-row`, скрытые и свёрнутые пропускаются) и идёт по ним: ↑/↓ — соседняя строка, Home/End — первая/последняя, PageUp/PageDown — ±10, выбранная строка прокручивается в вид.

### 3. Группы
- Клик по заголовку группы сворачивает/разворачивает её; caret ▼/▶, в свёрнутом виде остаются название и счётчик (`6`, `4 · 1 новых`).
- Правый клик по заголовку — меню «Свернуть все» / «Развернуть все» (для всех групп текущего списка).
- Состояние хранится в `localStorage["soroka...psed"]` и переживает перезапуск.
- Свёрнутые строки скрываются, поэтому навигация стрелками их пропускает, а выделение открытого письма восстанавливается после перерисовки.

### 4. Адресная книга
- Новое окно «Адресная книга» в шапке: список контактов, поиск по имени/адресу/организации, карточка (имя, e-mail, организация, должность, телефон, группы, заметки).
- Кнопки: «Новый», «Сохранить», «Удалить», «Импорт», «Экспорт».
- Импорт: CSV (разделитель `;` или `,`, заголовки необязательны) и vCard 3.0/4.0.
- Экспорт: CSV для Excel (`;`, BOM) и vCard; файл сохраняется в `%USERPROFILE%\Downloads\soroka-contacts.csv|.vcf` — WebView2 не сохраняет Blob-файлы, поэтому запись делает Rust.
- «✨ Заполнить по письму»: ИИ читает последнее письмо от адреса (кроме спама и корзины), извлекает имя, организацию, должность, телефон и заметку, заполняет карточку — сохраняет человек.
- Хранение: таблица `contacts` в `soroka.db`, уникальный индекс по e-mail без учёта регистра.

### 5. Автодополнение в «Кому»
При вводе от 2 символов выпадает список: сначала контакты, затем адреса из переписки (по `From`), без папок «Спам», «Junk», «Корзина» и без писем категории «Реклама». Для истории показывается число писем. ↑/↓ — выбор, Enter — подставить, Esc — закрыть; несколько адресов — через запятую.

## Ограничения
- Для автодополнения используются адреса отправителей (`From`). Адреса из полей «Кому»/«Копия» в кэш не пишутся — это отдельная задача (нужно сохранять получателей при синхронизации).
- Автодополнение сделано только для поля «Кому»: в форме нового письма нет «Копии» и «Скрытой копии».
