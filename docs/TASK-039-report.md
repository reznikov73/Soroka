# TASK-039 — перетаскивание окна, команды трея и сворачивание в трей

Версия: **0.36.1**. Дата: 2026-10-21.

## 1. Медленное перетаскивание окна
Нативный `data-tauri-drag-region` запускает модальный цикл Windows: WebView2 в это время почти не перерисовывается, поэтому окно «плывёт» рывками. Атрибуты `data-tauri-drag-region` убраны; перетаскивание делает фронтенд:
- `pointerdown` на заголовке запоминает экранную точку, позицию окна (`outerPosition`) и масштаб;
- `pointermove` через `requestAnimationFrame` вызывает `setPosition` с новой позицией;
- `pointerup`/`pointercancel` завершают, `setPointerCapture` не теряет мышь за пределами окна.
Добавлены разрешения `allow-set-position`, `allow-outer-position`, `allow-scale-factor`.

Проверка вживую: окно стояло в `80,60`, после протяжки на 125×75 px стало `205,135` — то есть двигается ровно за курсором.

## 2. Команды трея
Раньше пункты меню только отправляли событие в webview — если слушатель не срабатывал, ничего не происходило. Теперь действия выполняются в Rust:
- «Открыть POS Mail» / «Свернуть в трей» — прямое управление окном (`show`, `unminimize`, `set_focus` / `hide`);
- «Проверить почту» — вызывает `commands::sync_inbox` (синхронизация идёт даже без участия JS);
- «Выход» — чистит корзины отмеченных ящиков через `empty_trash_account`, затем `app.exit(0)`.
Каждое действие пишется в журнал: `трей: open|hide|check|quit`, при создании значка — `трей: создан`.

Проверка: в журнале есть `трей: создан`; строка `empty_trash_account 4` + `трей: выход` появилась после нажатия «Выход» в меню трея (16:58), процесс завершился.

## 3. Сворачивание в трей
Кнопка «—» теперь вызывает `hide()` (разрешение `core:window:allow-hide`), окно исчезает с панели задач, процесс живёт. Вернуть — левый клик по значку в трее или меню «Открыть POS Mail».

Проверка: после клика по «—» процесс жив (`process alive=True`), окно `POS Mail` имеет `visible=False`; после `ShowWindow` возвращается.

## Замечание про значок
Windows 10 по умолчанию прячет новые значки в переполнение «^» на панели задач. Если значка не видно — раскройте «^» и перетащите сороку на панель (или включите «Показывать все значки»). Без этого окно, свёрнутое в трей, можно вернуть повторным запуском exe.
