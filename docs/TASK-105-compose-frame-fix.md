# TASK-105 — Починка окна редактора после 0.46.53

Дата: 2026-11-17. Версия: 0.46.54.

## Что случилось

В 0.46.53 я задумал сделать окно редактора обычным окном Windows, но правка не дошла до файла: пакет изменений был атомарным, один из фрагментов не совпал, и записалось ничего. А следом отдельной правкой я убрал нашу шапку и функцию `initComposeWindowChrome()`. В итоге у окна не осталось **ни системной рамки, ни своей**: двигать не за что, растягивать нечем, вид — обрезанный.

Вторая причина «уродливого» вида: `#compose-overlay` в режиме окна оставался `position: static` (наследие TASK-019.2), поэтому карточка с `height: 100%` не получала высоту и сжималась по содержимому — снизу торчал фон окна серой полосой.

## Исправлено

- Окно редактора создаётся с `decorations: true` и `resizable: true` — системный заголовок, системные кнопки и системный ресайз. Наша шапка в нём скрыта.
- `body.compose-window #compose-overlay` теперь `position: fixed; inset: 0` — карточка занимает всю клиентскую область, серой полосы нет.
- Закрытие окна по системному крестику сохраняет черновик: обработчик `onCloseRequested` → `saveDraftNow(true)` уже был и продолжает работать.

## Сделано

- `src/main.ts` — `decorations: true`, `resizable: true` у окна редактора (с проверкой, что правка легла в файл).
- `src/styles.css` — `position: fixed` у оверлея редактора.
