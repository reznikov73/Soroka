## 1. «Не удалось обновить папку «Drafts»: сервер не отдал ни одного письма этой папки»

Симптом (скриншот 2 пользователя): тост с ошибкой на папке Drafts ящика `rez@poson.ru`, список показывает письмо из кэша.

Причина: `fetch_headers` при пустом результате возвращал `Err("сервер не отдал ни одного письма этой папки")` — это появилось в 0.29.1 как защита, но получилось слишком громко: у Majordomo и Яндекса сервер отвечает `[UNAVAILABLE]` на конкретное письмо, и если в папке всего одно письмо, «частично» = «ничего».

Исправление:
- `fetch_headers` при пустом результате возвращает `Ok((total, vec![]))` и пишет `WARN … сервер не отдал ни одного письма из N`;
- `sync_folder` при `headers.is_empty() && total > 0` **не** перезаписывает кэш и состояние, пишет `WARN sync_folder …: сервер не отдал писем — кэш оставлен как есть`, отдаёт `fetched = 0`;
- `sync_inbox` — та же защита: `save_sync` и подмена состояния пропускаются, кэш остаётся.

Проверка на живом ящике (v0.29.2, лог):

```
12:57:00 WARN FETCH 1:1: сервер ответил ошибкой — [UNAVAILABLE] FETCH Completed …
12:57:00 WARN FETCH 1:1: письмо не отдаётся сервером — …
12:57:00 WARN Drafts: сервер не отдал ни одного письма из 1
12:57:00 WARN sync_folder 4::Drafts: сервер не отдал писем — кэш оставлен как есть
```

В окне: папка открывается, показывает кэш, статус «почта: папка «Drafts», писем 1», тоста об ошибке нет (`t292-2-acc3.png`). Ошибки нет — есть одна строка в логе.
