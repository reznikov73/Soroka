# TASK-011 — Удобная компоновка: список v2, панели, даты, выделение

**Цель:** по отзыву пользователя — убрать «шум» из списка, сделать панели управляемыми, даты — по-русски, выделение — заметным.
Макеты: `.openclaw/tmp/mockups/mock6-list-v2.png` (список — закреплён), `mock5-panels.png` (панели — направление).

## Часть A. Список писем v2 (закреплено пользователем)

- Кругов с буквами **нет вообще** — строка от края до края.
- Бейдж категории — **на первой строке, перед темой**: `[Финансы] Защитите финансы… ★`.
- Строка = 3 линии: (1) бейдж + тема + дата справа, (2) отправитель, (3) сводка «✦ …».
- «★» — у писем с важностью «высокая» (и они по-прежнему сверху списка).
- Нет разбора — нет бейджа, тема от самого края.
- Длинная тема обрезается «…», дата остаётся справа; непрочитанность — точка, флаг ⚑ — как есть.

## Часть B. Даты по-русски (и фикс UTC)

Сейчас время берётся regex-ом из «сырой» строки — это UTC (для Москвы врёт на 3 часа). Правильно:
парсить `new Date(str)` и форматировать в локальном времени:
- список: сегодня `13:27`; вчера `вчера`; этот год `13 окт`; старше `13.10.25`;
- карточка письма: `15 октября 2026, 13:27`;
- цитата при ответе/пересылке: та же полная форма.

## Часть C. Выделение

- Активная папка: заливка `rgba(96,205,255,.16)` + жирный + полоса слева (как есть).
- Активное письмо: заливка сильнее текущей + полоса слева + текст белым; **держится, пока не выберешь другое** (не гаснет при уходе фокуса).
- Hover — деликатный, заметно тише, чем selected.

## Часть D. Панели

- Разделители между панелями: тянутся мышью (pointer events), курсор `col-resize`;
  двойной клик — сброс (232/356); ограничения: папки 170–420, список 260–680.
- Свёртывание: у папок и списка — кнопки «⟨» в шапке; свёрнутая панель = полоска 46px

- Ширины и состояние сворачивания сохраняются между запусками (localStorage `soroka.layout`).
- НЕ входит: перестановка панелей местами, прозрачность панелей (объяснено: acrylic уже есть).
