# TASK-019 — отчёт: кэш по папкам, мгновенные переходы, цифры непрочитанных

## Что сделано
- **Кэш писем по папкам.** Таблица `messages` получила ключ `(folder, uid)` и колонку `folder`; письма каждой папки хранятся отдельно. Старая таблица (одна папка) мигрирует автоматически — пересоздаётся при первом запуске.
- **Мгновенное переключение папок.** При клике по папке `selectFolder` сначала вызывает `load_folder` — чтение из SQLite без сети; список рисуется сразу. Затем в фоне идёт `sync_folder`, после него — обновление списка и счётчиков. Ошибка сети больше не оставляет пустой экран: показывается кэш и тост «сервер прервал соединение — показан кэш».
- **Цифры непрочитанных на каждой папке.** Новая таблица `folder_stats(folder, total, unseen)`; цифра выводится у каждой папки, у карточки ящика — сумма по его папкам. После проверки почты `refresh_unread` запрашивает IMAP `STATUS (MESSAGES UNSEEN)` по всем папкам ящика за одно соединение.
- **Отметки работают во всех папках.** `mark_seen` / `mark_flagged` принимают ключ папки, обновляют кэш и корректируют `unseen` в `folder_stats` (только при реальном изменении флага).
- **Счётчик в UI** обновляется локально (`bumpUnread`) после «прочитано/непрочитано», не дожидаясь сети.

## Замечания
- Папка, которую ещё ни разу не открывали, при первом заходе ждёт сервер (кэша нет) — это ожидаемо; со второго раза открывается мгновенно.
- Автоматические клики по папкам иногда не доходят (окно перетаскивается/теряет фокус), поэтому часть проверок сделана по состоянию БД и статусу внизу.
