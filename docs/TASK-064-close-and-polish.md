# TASK-064 — крестик закрывает программу и доводка по макету

Дата: 2026-11-04. Версия: 0.46.16.

## 1. Крестик и трей

**Наблюдаемый факт:** нажатие на крестик не закрывает программу.

**Причина:** в настройках `minimize_to_tray: true`, а обработчик закрытия с версии 0.46.0 трактовал эту опцию одинаково для «свернуть» и «закрыть» — окно пряталось в трей. Поведение не было поломкой, но противоречит привычному: крестик должен закрывать.

**Исправлено:**
- крестик всегда закрывает программу (с очисткой корзин, если она включена);
- в трей прячет только кнопка «свернуть»;
- ожидание очистки корзин при закрытии сокращено с 8 до 3 секунд, чтобы окно не «зависало» на медленном сервере.

## 2. Доводка по макету

- **Дата** переехала на строку отправителя, к правому краю. В плотном режиме остаётся в строке.
- **Тема письма** в панели чтения увеличена до 22 px, вес 700.
- **Кнопки действий** («Ответить», «Ответить всем», «Переслать», «Черновик», «В корзину») получили иконки; кнопки выровнены по центру, иконка 14 px.
