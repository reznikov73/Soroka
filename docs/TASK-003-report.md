## Технические факты

- `rusqlite = "0.40"` (features `bundled`) — SQLite вкомпилирован в exe, внешних DLL нет.
- Схема: `messages(uid PK, seq, from_addr, subject, date)` / `folders(name PK)` / `meta(key PK, value)`; создаётся идемпотентно.
- `sync_inbox`: сеть → `save_sync()` (транзакция, полная замена) → состояние + событие `sync-finished`; при ошибке → `load()` кэша → payload `offline: true` (+ текст ошибки).
- UI: при старте — `load_cache` (мгновенный список) → автосинхронизация обновляет; офлайн — статус «почта: офлайн, писем N».
- Офлайн-тест без вмешательства в сеть: env-переопределение `SOROKA_IMAP_HOST/PORT` на нерабочий адрес.
