# TASK-028 — адресная книга 2.0

Версия: **0.28.0**. Дата: 2026-10-20. Макет-основание: `DELIVERY/soroka-contacts-mockups.html`, выбран вариант **C + A** (палитра как вход, карточка и список как рабочая область).

## Что сделано

### 1. Экран книги

- Сверху — поиск «Найти человека или адрес…» и кнопки «+ Контакт», «Импорт», «Экспорт», «✕».
- Слева — чипы групп с количеством («Все», группы из карточки, «Из переписки») и список: кружок с инициалами, имя, адрес/организация.
- Справа — карточка: крупные инициалы, имя, адрес, поля (организация, должность, телефон, группы, заметки) и статистика «Писем: N · последнее <дата>».
- Режимы карточки: просмотр (кнопки «Написать», «В письмо», «Изменить», «Удалить») и правка (поля и «Сохранить», плюс «✨ Заполнить по письму»).

### 2. Клавиатура

- `↑`/`↓` — переход по списку, фокус остаётся в поиске;
- `Enter` — новое письмо выбранному человеку;
- `Ctrl+Enter` — открыть карточку на правку;
- `Esc` — закрыть книгу.
Пока книга открыта, стрелки не перехватываются списком писем (`modalOpen()` уже учитывает оверлей).

### 3. «Из переписки»

Новый бэкенд-метод `Store::correspondence_contacts` (SQL по `messages` с исключением папок spam/junk/trash/спам/корзина и записей `ai_analysis` с категорией «реклама»), исключает адреса, уже имеющиеся в `contacts` (без учёта регистра). В UI — чип «Из переписки N», строки с числом писем и кнопкой «Сохранить»; после сохранения строка исчезает, книга переключается на «Все» и открывает созданную карточку.

### 4. «+ В книгу» в письме

Кнопка в панели письма рядом с «Переслать»: берёт адрес отправителя, при отсутствии в книге сохраняет контакт и показывает тост «Контакт добавлен», иначе — «Уже в книге».

### 5. Статистика адреса

`Store::mail_stats(email)` — число писем от адреса и дата последнего (по кэшу `messages`, сортировка по `rowid`, то есть по порядку загрузки). Команда `contact_stats`.
