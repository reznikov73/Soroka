# TASK-016 — Несколько почтовых ящиков

**Статус:** выполнено в v0.15.0. **Дата:** 2026-10-18.

## Зачем
До сих пор «Сорока» умела один ящик. Нужно как в The Bat!: несколько учётных
записей, у каждой — свои папки, свой кэш, своя отправка; настройки каждого
ящика открываются отдельно.

## Что сделано
1. **Список ящиков** — `%APPDATA%\Soroka\accounts.json`:
   `{"accounts": [{id, email, password, imap_host, imap_port, smtp_host, smtp_port}]}`.
   Старый `account.json` (TASK-015) читается один раз и превращается в ящик с id «1».
   Пароли в интерфейс не отдаются: наружу идёт `AccountView` без пароля.
2. **Ключ папки** — `id::ИМЯ` (`accounts::folder_key` / `split_key` / `resolve_cfg`).
   Все команды, работающие с папкой (тело, прочитано, важное, спам, вложения,
   синхронизация, ИИ-разбор, черновик ответа), берут настройки подключения из
   ключа, поэтому письмо всегда знает свой ящик.
3. **Кэш** — `save_sync(account_id, …)` переписывает папки только своего ящика,
   в `meta` хранится `account`; `CachedMail.account` и `CacheInfo.account`
   позволяют не показывать чужой кэш под активным ящиком.
4. **Панель папок** — карточка на ящик: активный раскрыт (папки с иконками,
   названия по-русски: INBOX → «Входящие»), остальные свёрнуты; счётчик
   непрочитанных у активного и запомненный — у остальных; внизу «＋ Добавить ящик».
5. **Меню ящика** (правый клик): «Открыть ящик», «Проверить почту»,
   «Настройки ящика…», «Добавить ящик…».
6. **Мастер настройки** — «⚙ Настройки» правит активный ящик, «Добавить ящик»
   открывает пустую форму с заголовком «Новый ящик». Пустой пароль у
   существующего ящика = не менять.
7. **Отправка** — `send_mail(account_id, …)` через SMTP выбранного ящика;
   UI передаёт активный ящик.

- Удаления ящика пока нет (появится вместе с «Сорока-помощник», TASK-018).
