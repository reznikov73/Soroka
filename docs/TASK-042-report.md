# TASK-042 — редактор и список по макету

Версия: **0.39.0**. Дата: 22.10.2026.

## Что сделано

### Редактор
- Поля «Кому», «Копия», «Скрытая» отдельными строками с подписями слева, как в макете. Скрытая копия уходит на SMTP, но не попадает в заголовки (`lettre` по умолчанию вырезает `Bcc`).
- Панель форматирования: жирный, курсив, подчёркивание, список, ссылка. Тело письма стало `contenteditable`; отправляется `multipart/alternative` (HTML + текстовый дубль), вложения — `multipart/mixed`.
- **Отмена отправки 7 секунд**: при «Отправить» письмо попадает в очередь, окно закрывается, внизу тост с «Отменить». Отмена возвращает получателей, копии, текст и вложения в редактор; по истечении 7 секунд уходит на SMTP.
- Подпись вставляется один раз; при отмене отправки повторно не дублируется (проверено).

### Список
- Размеры и цвета по макету: тема 12.8 px, отправитель 12.4 px, сводка ИИ 11.4 px, отступы строки 9/12/14 px.
- Метки категорий — пастельные капсом 9 px, без рамки.
- Полоски цвета ящика вместо точек; счётчик группы «2 письма / 5 писем» (русская плюрализация).
- Заголовки групп: 10 px, трекинг 0.08em, жирность 700.
- Кнопка «Ответить» — акцентная.

### Цитата
- В текстовом письме цитата (`--- Исходное письмо ---` или строки `>`) сворачивается в кнопку «Показать цитату · N строк»; повторный клик скрывает.

## Ограничения
- Очередь отправки живёт в памяти: если закрыть программу в эти 7 секунд, письмо не уйдёт. Перенос очереди на диск — следующий шаг.
- Ссылка в форматировании вставляется через системный ввод URL (`prompt`); если WebView2 его заблокирует, кнопка не сработает — проверено не было.
- Вложения в очереди не сохраняются между запусками.
- Черновики теперь хранят HTML-тело; старые черновики открываются как обычный текст.
- Во время проверки ушло одно тестовое письмо на `rez@poson.ru` (отменить не успел из-за задержки на чтение скриншота).
