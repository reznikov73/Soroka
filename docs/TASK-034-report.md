# TASK-034 — черновики, «+ В книгу», пустые папки и верхняя панель

Версия: **0.31.0**. Дата: 2026-10-20.

## 1. Двойной клик по черновику открывал письмо только один раз
Причина: `selectMessage` после первого клика перерисовывает список, строка `<li>` заменяется новой — браузерный `dblclick` в такой ситуации не срабатывает, потому что второй клик приходит уже по другому элементу.
Решение: двойной клик определяется вручную — в обработчике `click` запоминаются UID и время; второй клик по тому же письму в пределах 420 мс открывает редактор черновика. Плюс запасной поиск черновика по теме, если UID изменился после автосохранения.

Проверка: `t310-9-draft-open1.png` (первое открытие), `t310-11-draft-open3.png` (повторное открытие того же черновика после Esc).

## 2. «+ В книгу» молча сохранял контакт
Теперь открывается адресная книга с уже заполненной карточкой (имя и адрес из письма), поля редактируются, есть «Сохранить», закрытие по Esc/×; если контакт уже есть — открывается на редактирование.
Реализация: `beginNewContact(name, email, note)` + `addCurrentSenderToBook` через `openContacts()`.

Проверка: `t310-7-bookform.png` — карточка «Витрина Подарков / podarok@flocktory.com» с активными полями.

## 3. В «Черновиках» висит письмо, а списка нет
Причина: Яндекс не отдаёт это письмо ни одним FETCH (`[UNAVAILABLE]`), клиент корректно его пропускал, но счётчик показывал серверный total — выглядело как «письмо есть, а списка нет».
Решение:
- список объясняет ситуацию: «На сервере N писем, но сервер не отдал их содержимое — нажмите «Обновить» позже» (`emptyListText()`, состояние `folderTotals`);
- добавлен повторный FETCH без `BODYSTRUCTURE` (`HEADER_QUERY_LITE`) — часть серверов ломается именно на нём.

Проверка: `t310-4-drafts.png` — понятное сообщение вместо пустого экрана.

## 4. Верхняя панель
Кнопки были фиксированной ширины 44 px, из-за чего «Адресная книга» переносилась на две строки. Теперь: иконки SVG + подписи, `white-space: nowrap`, высота 30 px, разделители, аккуратный hover, кнопки окна — иконки 34 px.
Проверка: `t310-1-topbar.png`.

## 5. Мелочи эргономики
- Кнопка «⟳» в строке поиска — обновить текущую папку (со спиннером).
- `Ctrl+R` — то же с клавиатуры, `/` — фокус в поиск, `Esc` в поиске — очистить.
