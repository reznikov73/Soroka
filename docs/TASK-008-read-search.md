# TASK-008 — Прочитано/непрочитано и поиск

**Цель:** письма различают непрочитанные (акцентная точка + жирная тема); открытие помечает письмо
прочитанным (в т. ч. на сервере, IMAP `\Seen`); кнопка возвращает «непрочитано»; мгновенный поиск
по загруженным письмам (тема/отправитель).

## Поведение

1. Список: непрочитанные — акцентная точка слева от времени и жирная тема; прочитанные — обычные.
2. Открыл письмо → оно помечается прочитанным (на сервере `UID STORE +FLAGS (\Seen)`); точка исчезает.
   Флаг переживает перезапуск (приходит с сервера при синхронизации).
3. Кнопка «Непрочитано» в панели письма: снимает `\Seen` (и на сервере); точка возвращается.
4. Поиск: поле над списком, фильтрует по теме и отправителю по мере ввода (регистр не важен);
   ничего не найдено — «Сорока ничего не нашла». Поиск по загруженным письмам (текущий список);
   серверный поиск по всему ящику — отдельная задача.
5. Офлайн: пометка не проходит — понятный тост (сеть нужна для IMAP STORE).
