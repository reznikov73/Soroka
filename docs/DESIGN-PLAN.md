## 3. План по слоям

### Слой 1. Токены (обе темы)

- Заменить акцент: светлая `#4f46e5`, тёмная — производный `#8b83ff` с проверкой контраста.
- Фон и подложки светлой темы: `#ffffff`, `#f7f8fa`, `#eef1f6`, `#e8ebf5`.
- Границы `#e3e7ee`/`#eef1f5`, текст `#1a2233`, вторичный `#5d6b85`, третичный `#8a96ad`.
- Свести радиусы к 6/8 px там, где сейчас 7 px.
- Тени — из макета.

Компоновка не меняется. Приёмка: обе темы, контраст AA, поиск остатков старых синих через `rg "#2f6fd8|#0f6cbd|#60cdff"`.

### Слой 2. Шапка

- Лого + название + версия слева, глобальное поле поиска по центру, иконки справа.
- Сохранить `data-tauri-drag-region` и кнопки окна — иначе окно перестанет перетаскиваться и закрываться.
- Поиск переезжает из панели списка в шапку; кнопки области поиска, сортировки и обновления — в строку над списком.

### Слой 3. Сайдбар

- Аватары-буквы с цветом ящика, SVG-иконки папок, счётчики «1 / 13», активная папка с заливкой и полосой.
- Кнопки «Написать» и «Проверить почту» — как в макете.

### Слой 4. Список

- Группы с цветной точкой и числом.
- Звезда (у нас есть флаг), имя отправителя жирным, тема, сниппет, дата справа.
- Действия при наведении — иконками.

### Слой 5. Панель письма

- Аватар, имя, чип категории, адрес, дата.
- Кнопки действий с иконками; «Разбор письма» — карточкой с кнопками.
- Типографика тела письма из макета.

### Слой 6. Тёмная тема

- В макете её нет: значения вывести из светлых, проверить контраст AA для текста, границ и акцента.

## 4. Риски

- **Светлая тема собрана из сотен точечных переопределений**, а не только токенов: после смены палитры останутся жёстко заданные синие. Нужен проход по `rg "#[0-9a-f]{6}"` с заменой на переменные.
- **Поиск в шапке** обещает «по письмам, людям, вложениям», а у нас поиск только по письмам. Либо менять подпись, либо делать поиск по контактам отдельной задачей.
- **Сетка макета фиксированная**, у нас перетаскиваемая. Предлагаю сохранить перетаскивание — это функция, а не оформление.
- **Объём:** слои 1–2 — один релиз, слои 3–4 — второй, слой 5 — третий.

## 5. Что нужно от пользователя

Выбрать: начинать со слоя 1 (токены, низкий риск) или делать полный редизайн одним заходом.
