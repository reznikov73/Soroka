# TASK-051 — быстрое окно настроек

Версия: 0.46.2. Дата: 26.10.2026.

## Что сделано
- Окно настроек переведено с нативного заголовка на собственный быстрый заголовок, как у главного окна: перетаскивание через pointermove + setPosition.
- Кнопки свернуть, развернуть, закрыть; двойной клик по заголовку разворачивает.
- Добавлены восемь краёв/углов для изменения размера через startResizeDragging.
- Главное окно блокируется на время настроек, повторное открытие поднимает существующее окно.
- Скрыты лишние кнопки главного заголовка в окне настроек.

## Проверка
- npm run build — ok; cargo check — ok; cargo tauri build — ok; exe 7.55 МБ, установщик 2.86 МБ.
- p0462-2-settings.png — окно настроек с собственным заголовком, кнопка «+ Категория» не пересекается с закрытием.
- Win32: главное окно disabled=False? Проверено: mainEnabled=False, пока настройки открыты.
- Синтетическое перетаскивание заголовка не сдвинуло окно: mouse_event не создаёт pointermove в WebView2. Живую проверку мышью нужно сделать пользователю.

## Не проверено
- Плавность перетаскивания реальной мышью после смены заголовка.
- Работа краёв изменения размера.
