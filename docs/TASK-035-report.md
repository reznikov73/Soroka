# TASK-035 — папки по-русски, счётчики и вид верхней части списка

Версия: **0.32.0**. Дата: 2026-10-20.

## 1. Кнопки рядом с поиском (P4)
Было: «в папке», «⟳», «✓», «⇅» — четыре кнопки с разной высотой и разными рамками, выглядели как случайный набор.
Стало: одна группа с общей рамкой и разделителями, высота 28 px, единые состояния наведения. Внутри — переключатель области поиска, обновление папки, выделение всех и сортировка.
Файлы: `index.html` (обёртка `.search-tools`), `styles.css`.

## 2. Кнопка сворачивания панели (P5)
Была отдельная кнопка `⟨` в заголовке панели, из-за неё заголовок «Папки» и кнопка «Написать» съезжали вниз.
Стало: кнопка абсолютно позиционирована в правом верхнем углу панели и появляется только при наведении (плюс по фокусу с клавиатуры). Место в раскладке не занимает.
Файлы: `styles.css` (`.pane-head`, `.pane-fold`).

## 3. Удалённая папка остаётся в дереве (P5)
Причина: список папок обновлялся только при полной синхронизации ящика, а кэш удалённых папок не чистился.
Сделано:
- `store::prune_folders` — удаляет из кэша письма, тела и счётчики папок, которых больше нет в списке сервера; вызывается автоматически из `save_folders` (то есть при каждой синхронизации);
- новая команда `refresh_folders` — перечитывает IMAP LIST при открытии ящика и по кнопке «⟳»;
- в журнал пишется строка «папки, удалённые на сервере: …».
Файлы: `store.rs`, `commands/mod.rs`, `lib.rs`, `main.ts`.

## 4. Русские имена папок (P6)
Серверы (Mail.ru, Яндекс, Gmail, Outlook) отдают системные и «умные» папки по-английски, а в веб-интерфейсе показывают по-русски. Добавлена таблица псевдонимов `FOLDER_ALIASES`:
`INBOX` → Входящие, `Sent`/`Sent Items`/`Sent Mail` → Отправленные, `Drafts` → Черновики, `Trash`/`Deleted Items` → Удалённые, `Junk`/`Spam`/`Junk Email` → Спам, `Archive` → Архив, `Outbox` → Исходящие, `Templates` → Шаблоны, `Newsletters` → Рассылки, `Public services` → Публичные сервисы, `Receipts` → Чеки, `Social` → Социальные сети, `ToMySelf` → Письма себе, `Important` → Важное, `Starred` → Помеченные, `[Gmail]/All Mail` → Вся почта.
Значки папок теперь тоже определяются по русскому имени.

## 5. Счётчики в заголовке ящика (P3)
В строке ящика показывается `3 / 128` — непрочитанные и всего, с подсказками. Цифры пересчитываются при чтении письма, пометке «прочитано/непрочитано», синхронизации и смене папки (через `sumUnread`/`sumTotal` и `renderFolders`). Если непрочитанных нет — просто общее число.

## 6. Счётчик непрочитанных в заголовке окна (P3)
`getCurrentWindow().setTitle()` вызывается из `renderFolders`: заголовок становится «(3) Сорока». Обновление идёт и при локальных изменениях, и после синхронизации; лишние вызовы отсекаются кэшем последнего заголовка.
