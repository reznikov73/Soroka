# TASK-019 — кэш писем по папкам, мгновенные переходы, цифры непрочитанных

## Цель
Переключение папок должно быть мгновенным (из локального кэша), а на каждой папке — цифра непрочитанных.

## Требования
1. Письма каждой папки хранятся в локальной БД отдельно; открытие одной папки не стирает кэш другой.
2. При клике по папке список показывается сразу из кэша (без ожидания сети), затем тихо обновляется с сервера.
3. Если кэша папки нет — показывается «загрузка…», как раньше, и выполняется сетевой запрос.
4. На каждой папке — число непрочитанных; на карточке ящика — сумма по его папкам.
5. После проверки почты счётчики обновляются по IMAP STATUS для всех папок ящика.
6. Отметки «прочитано/непрочитано» и «важное» работают в любой папке и корректируют счётчик.
7. Старый кэш (одна папка) мигрирует автоматически.

## Реализация
- `store.rs`: схема `messages(folder, uid, …)` с PRIMARY KEY (folder, uid), таблица `folder_stats(folder, total, unseen)`, миграция старой таблицы, `save_folder_sync`, `load_folder`, `save_folders`, `set_meta`, `unread_counts`, `load_folders`, `mark_seen(folder, uid, seen)`, `mark_flagged(folder, uid, flagged)`.
- `imap.rs`: `folder_statuses(cfg, mailboxes)` — STATUS (MESSAGES UNSEEN) по всем папкам за одно соединение.
- `commands`: `load_folder`, `get_unread_counts`, `refresh_unread`; `sync_folder` пишет кэш папки.
- `main.ts`: кэш-первый `selectFolder`, `unreadByFolder`, `sumUnread`, `refreshUnread`, `refreshUnreadFromServer`, `bumpUnread`.

## Приёмка
- `cargo test` — включая новый тест `folders_cache_is_independent` (папки не затирают друг друга, счётчик меняется только у своей папки).
- `npm run build`, `cargo clippy` — без ошибок.
- Живая проверка: повторное открытие папки показывает список мгновенно; цифры видны на всех папках.
