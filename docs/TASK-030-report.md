# TASK-030 — подпись у каждого ящика и «Улучшить» в редакторе

Версия: **0.29.0**. Дата: 2026-10-20. Основание: `DELIVERY/soroka-signature-mockups.html`, выбран вариант **A**.

## 1. Подпись ящика

- Новые настройки: `account_signatures: [{ account_id, text, enabled }]` (`src-tauri/src/settings.rs`), помощники `Settings::account_signature` / `set_account_signature`.
- В карточке ящика («Настройки → ящик») появился блок «Подпись ящика»: галочка «Добавлять подпись в новые письма», редактор, панель макросов (%FromName, %Date, %Time, %Cursor), счётчик символов и кнопка «Сохранить подпись» (сохраняет только подпись, без перепроверки сервера).
- Миграция: пока у ящика нет своей подписи, подставляется старая общая (`signatures` с `is_default`). Список подписей в письме сократился до «Подпись ящика» / «Без подписи».
- Раздел «Подписи» в настройках теперь показывает список ящиков с превью подписи и кнопкой «Изменить» (переход в карточку ящика).

## 2. «Улучшить» подпись

- Новая команда `improve_signature(text)` → `Vec<SignatureVariant{title,text}>` (`ai/gigachat.rs::signature_variants_with`, парсер `parse_signature_variants` с запасным вариантом, если модель ответила не JSON).
- Промпт просит три варианта: «Короче и аккуратнее», «Официальнее», «С макросами»; переносы строк экранируются как `\n`, факты не выдумываются.
- В UI: кнопка показывает «Думаю…», затем три карточки с «Применить»; текст меняется только по кнопке.
