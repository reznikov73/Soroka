# Сорока (Soroka)

Каркас почтового клиента для Windows (аналог The Bat! с ИИ-модулем): Rust + Tauri 2, интерфейс — Vite + TypeScript. Текущая версия — **0.17.0** (сортировка и группировка писем: кнопка «⇅» рядом с поиском, группы по датам или категориям; светлая и тёмная темы одной кнопкой; несколько ящиков — панель папок по аккаунтам).

## Запуск (разработка)

Проще всего — из VS Code: открыть папку проекта и запустить задачу **«Запуск Сороки (tauri:dev)»** (Ctrl+Shift+B) — поднимется dev-сервер и откроется окно. Отладка — F5 («Отладка Сороки (Rust)»).

Из терминала:

```powershell
. .\scripts\devshell.ps1   # активировать окружение (Rust + MSVC) — обязательно
npm install                # один раз
cargo tauri dev
```

Пока задача работает, интерфейс доступен и в браузере: http://localhost:1420

## Почта (IMAP + SMTP)

Загрузка писем идёт с реальных ящиков. Учётные записи (вне репозитория) — `%APPDATA%\Soroka\accounts.json` (список; прежний `account.json` переносится автоматически):

```json
{ "email": "user@mail.ru", "password": "<пароль для внешних приложений>", "imap_host": "imap.mail.ru", "imap_port": 993 }
```

(или переменные окружения `SOROKA_IMAP_USER` / `SOROKA_IMAP_PASS`). Кнопка «Проверить почту» или автосинхронизация при запуске загружает последние 30 писем INBOX; по завершении — тост «Сорока на хвосте принесла — N писем». Письма и папки кэшируются в `%APPDATA%\Soroka\soroka.db`; без сети приложение показывает кэш (статус «почта: офлайн»). Отправка — кнопка «Написать» или Ctrl+N: поля Кому/Тема/Текст, отправить кнопкой или Ctrl+Enter, закрыть — Esc. SMTP-сервер выводится из IMAP-хоста (`imap.mail.ru` → `smtp.mail.ru:465`); можно задать `smtp_host`/`smtp_port` в account.json или переменными `SOROKA_SMTP_HOST`/`SOROKA_SMTP_PORT`. Клик по папке в списке слева загружает её письма (например, «INBOX/ToMyself» — куда mail.ru складывает письма, отправленные себе). Клик по письму загружает его тело: HTML рендерится безопасно (скрипты вычищаются, внешние картинки заблокированы), простые письма показываются текстом; тела кэшируются в SQLite и открываются офлайн. Можно отвечать и пересылать (с цитатой исходного), прикреплять файлы при отправке (≤ 15 МБ каждый, ≤ 20 МБ суммарно) и сохранять вложения из писем в «Загрузки». Внешние картинки по умолчанию скрыты — кнопка «Показать картинки» включает их для одного письма.

## Интерфейс

Две темы в стиле Fluent 2 — тёмная и светлая: одна кнопка в шапке показывает тему, на которую переключит («☀» из тёмной, «🌙» из светлой), выбор запоминается, а пока его нет — «Сорока» следует системной теме Windows. Акриловое окно (Mica на Windows 11; Acrylic на Windows 10) и системный заголовок перекрашиваются в тон теме; карточки писем с бейджем категории и сводкой; акцент тёмной темы `#60cdff`, светлой — `#0f6cbd`. Непрочитанные письма отмечены акцентной точкой и жирной темой; открытие помечает письмо прочитанным (и на сервере), кнопка «Непрочитано» возвращает флаг. Над списком — мгновенный поиск по теме и отправителю и кнопка «⇅»: сортировка «Сначала новые / Сначала старые» и группировка «По датам» (Сегодня, Вчера, На этой неделе, В этом месяце, Раньше), «По категориям» (Важное, категории ИИ, Без разбора) или «Без группировки». Выбор запоминается, у каждой группы — счётчик писем. Кнопка «✦ Разбор» просит у GigaChat структурированный разбор письма (ключ — вне репозитория: `SOROKA_GIGACHAT_KEY` или `%APPDATA%\Soroka\gigachat.json`). После синхронизации «Сорока» сама разбирает до 30 писем: в списке появляются сводка «✦ …» и бейдж категории, важные поднимаются наверх; в письме — карточка «Разбор» с кнопками «⚑ Важное» и «В спам» (+домен в чёрный список). Разборы кэшируются — модель повторно не вызывается. Панели («Папки», «Письма», «Письмо») свободно компонуются: перетаскивание за заголовок в любые комбинации рядов, сворачивание в полоски и плашки с плавным перераспределением места, разделители в двух направлениях; кнопка «Раскладка» — пресеты «Классика / Чтение / Моя» и сброс. Шапка письма компактная: тема и дата, отправитель и кнопки — две строки. Кнопка «Календарь» в шапке окна открывает планы: месячная сетка и список выбранного дня; события добавляются вручную — в карточке «Разбор» кнопка с датой («📅 …») открывает форму с заполненными полями, и событие появляется в календаре только после подтверждения (в карточке дня — «Открыть письмо», «Сохранить .ics», «Удалить»). Кнопка «✍ Черновик» в письме просит GigaChat написать ответ в вашем стиле по образцам из «Отправленных» — текст открывается в форме ответа, вы правите и отправляете сами. Кнопка «⚙ Настройки» (и автозапуск при первом старте) открывает мастер настройки ящика: пресеты Mail.ru / Яндекс / Gmail / Outlook / Rambler или ручной ввод серверов, с проверкой входа по IMAP. Окно письма двигается за заголовок и растягивается; кнопка «✨ Улучшить» переписывает набранный текст (орфография, ясность, деловой тон).

## Сборка релиза

Задача VS Code **«Сборка релиза (tauri:build)»** — сначала синхронизирует версию, затем собирает. Из терминала: `. .\scripts\devshell.ps1`, затем `cargo tauri build`.

Артефакты (v0.17.0):

- **Портативная программа:** `src-tauri\target\release\soroka.exe` — 6.37 МБ (запуск без установки).
- **Установщик:** `src-tauri\target\release\bundle\nsis\Soroka_0.17.0_x64-setup.exe` — 2.41 МБ.

При первом запуске Windows может показать предупреждение SmartScreen (установщик не подписан) — «Подробнее → Выполнить в любом случае».

## Структура проекта

- `src/` — интерфейс: `main.ts` (логика), `styles.css` (тема и свободная компоновка панелей), `assets/`.
- `src-tauri/` — бэкенд на Rust: `src/commands/` (почта: синхронизация, папки, письма, тела, отправка; ИИ: разбор), `src/mail/` (imap — приём, store — кэш, smtp — отправка; parser — заглушка), `src/ai/` (заглушки); `tauri.conf.json` — главный конфиг; `build.rs` — вшивание git-хеша.
- `scripts/` — окружение и сборка: `devshell.ps1` (Rust+MSVC), `vsc-task.ps1` (обёртка задач), `code.ps1` (запуск VS Code), `sync-version.ps1` (версия из одного места), `debug-prep.ps1` (подготовка F5).
- `.vscode/` — задачи, отладка, настройки проекта.

## Версионирование

Единственный источник версии — `src-tauri\tauri.conf.json` → `version`. Скрипт `sync-version.ps1` разносит её в `Cargo.toml` и `package.json`; имя установщика и версия в статус-баре берутся оттуда же. Релиз: изменить версию → задача tauri:build → запись в CHANGELOG.md → тег `vX.Y.Z`.

## Замеры (v0.17.0)

- exe — 6.37 МБ; установщик — 2.41 МБ (цель < 20 МБ выполнена).
- Предыдущие релизы: v0.14.0 — 6.34/2.40; v0.14.1 — 6.34/2.40; v0.15.0 — 6.37/2.41; v0.16.0 — 6.37/2.41 МБ.
- Память (релиз): в простое ≈ **449 МБ** (soroka.exe ≈33 МБ + WebView2 ≈416 МБ, 6 процессов) после активной работы с большим ящиком (143 письма в кэше); на чистом старте — ≈373 МБ. Колебания 340–450 МБ; переключение темы и группировки процессов не добавляет. Цель < 150 МБ на стеке WebView2 не достигается — зафиксировано; лёгкость — кросс-требование, замеры после каждой крупной задачи.
