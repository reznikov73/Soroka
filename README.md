# Сорока (Soroka)

Каркас почтового клиента для Windows (аналог The Bat! с ИИ-модулем): Rust + Tauri 2, интерфейс — Vite + TypeScript. Текущая версия — **0.10.0** (ИИ-разбор почты: сводки, важность, категории).

## Запуск (разработка)

Проще всего — из VS Code: открыть папку проекта и запустить задачу **«Запуск Сороки (tauri:dev)»** (Ctrl+Shift+B) — поднимется dev-сервер и откроется окно. Отладка — F5 («Отладка Сороки (Rust)»).

Из терминала:

```powershell
. .\scripts\devshell.ps1   # активировать окружение (Rust + MSVC) — обязательно
npm install                # один раз
cargo tauri dev
```

Пока задача работает, интерфейс доступен и в браузере: http://localhost:1420

## Почта (IMAP + SMTP)

Загрузка писем идёт с реального ящика. Учётка (вне репозитория) — `%APPDATA%\Soroka\account.json`:

```json
{ "email": "user@mail.ru", "password": "<пароль для внешних приложений>", "imap_host": "imap.mail.ru", "imap_port": 993 }
```

(или переменные окружения `SOROKA_IMAP_USER` / `SOROKA_IMAP_PASS`). Кнопка «Проверить почту» или автосинхронизация при запуске загружает последние 30 писем INBOX; по завершении — тост «Сорока на хвосте принесла — N писем». Письма и папки кэшируются в `%APPDATA%\Soroka\soroka.db`; без сети приложение показывает кэш (статус «почта: офлайн»). Отправка — кнопка «Написать» или Ctrl+N: поля Кому/Тема/Текст, отправить кнопкой или Ctrl+Enter, закрыть — Esc. SMTP-сервер выводится из IMAP-хоста (`imap.mail.ru` → `smtp.mail.ru:465`); можно задать `smtp_host`/`smtp_port` в account.json или переменными `SOROKA_SMTP_HOST`/`SOROKA_SMTP_PORT`. Клик по папке в списке слева загружает её письма (например, «INBOX/ToMyself» — куда mail.ru складывает письма, отправленные себе). Клик по письму загружает его тело: HTML рендерится безопасно (скрипты вычищаются, внешние картинки заблокированы), простые письма показываются текстом; тела кэшируются в SQLite и открываются офлайн. Можно отвечать и пересылать (с цитатой исходного), прикреплять файлы при отправке (≤ 15 МБ каждый, ≤ 20 МБ суммарно) и сохранять вложения из писем в «Загрузки». Внешние картинки по умолчанию скрыты — кнопка «Показать картинки» включает их для одного письма.

## Интерфейс

Тёмная тема в стиле Fluent 2: акриловое окно (Mica на Windows 11; Acrylic на Windows 10), своя шапка окна, карточки писем с аватарами отправителей, системный акцент `#60cdff`. Непрочитанные письма отмечены акцентной точкой и жирной темой; открытие помечает письмо прочитанным (и на сервере), кнопка «Непрочитано» возвращает флаг. Над списком — мгновенный поиск по теме и отправителю. Кнопка «✦ Разбор» просит у GigaChat структурированный разбор письма (ключ — вне репозитория: `SOROKA_GIGACHAT_KEY` или `%APPDATA%\Soroka\gigachat.json`). После синхронизации «Сорока» сама разбирает до 30 писем: в списке появляются сводка «✦ …» и бейдж категории, важные поднимаются наверх; в письме — карточка «Разбор» с кнопками «⚑ Важное» и «В спам» (+домен в чёрный список). Разборы кэшируются — модель повторно не вызывается.

## Сборка релиза

Задача VS Code **«Сборка релиза (tauri:build)»** — сначала синхронизирует версию, затем собирает. Из терминала: `. .\scripts\devshell.ps1`, затем `cargo tauri build`.

Артефакты (v0.10.0):

- **Портативная программа:** `src-tauri\target\release\soroka.exe` — 6.2 МБ (запуск без установки).
- **Установщик:** `src-tauri\target\release\bundle\nsis\Soroka_0.10.0_x64-setup.exe` — 2.35 МБ.

При первом запуске Windows может показать предупреждение SmartScreen (установщик не подписан) — «Подробнее → Выполнить в любом случае».

## Структура проекта

- `src/` — интерфейс: `main.ts` (логика), `styles.css` (грид 240px | 360px | 1fr), `assets/`.
- `src-tauri/` — бэкенд на Rust: `src/commands/` (ping, app_info, sync_inbox, load_cache, get_messages, get_folders, send_mail), `src/mail/` (imap — приём, store — кэш, smtp — отправка; parser — заглушка), `src/ai/` (заглушки); `tauri.conf.json` — главный конфиг; `build.rs` — вшивание git-хеша.
- `scripts/` — окружение и сборка: `devshell.ps1` (Rust+MSVC), `vsc-task.ps1` (обёртка задач), `code.ps1` (запуск VS Code), `sync-version.ps1` (версия из одного места), `debug-prep.ps1` (подготовка F5).
- `.vscode/` — задачи, отладка, настройки проекта.

## Версионирование

Единственный источник версии — `src-tauri\tauri.conf.json` → `version`. Скрипт `sync-version.ps1` разносит её в `Cargo.toml` и `package.json`; имя установщика и версия в статус-баре берутся оттуда же. Релиз: изменить версию → задача tauri:build → запись в CHANGELOG.md → тег `vX.Y.Z`.

## Замеры (v0.10.0)

- exe — 6.2 МБ; установщик — 2.35 МБ (цель < 20 МБ выполнена).
- Память (релиз): в простое ≈ **386 МБ** (soroka.exe ≈31 МБ + WebView2 ≈356 МБ, 6 процессов); с открытым HTML-письмом ≈ **419 МБ** (+33 МБ). Цель < 150 МБ на стеке WebView2 не достигается — зафиксировано; лёгкость — кросс-требование, замеры после каждой крупной задачи.
